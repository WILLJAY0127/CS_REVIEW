# CS70 知识库总览

## 8+1 总览卡

1. **课程定位**：CS70 是伯克利的离散数学与概率论，纯证明课。本质是"训练严谨推理"——给出任何命题，能判断真假、给出证明、量化不确定性。
2. **两大板块**：离散数学（确定性世界：逻辑 / 证明 / 数论 / 多项式）+ 概率论（不确定性世界：随机变量 / 期望 / 极限定理）。
3. **核心工具**：归纳法、反证法、期望线性性——三样东西贯穿全课、考试出现率最高。
4. **三个标志性应用**：Gale-Shapley 稳定匹配、RSA 公钥密码、秘密共享 / 纠错码——证明抽象数学可以直接变成工程系统。
5. **核心思维**：不接受"看起来对"；每个结论要么有定义支撑，要么有定理推导，要么有反例否定。
6. **评估维度**：证明的严谨完整性 / 计数不重不漏 / 随机变量建模 / 不等式放缩。
7. **三道门槛**：归纳证明（尤其是强归纳）、模逆元与 RSA 全流程、随机变量建模（把自然语言翻译成 X、Y、事件）。
8. **本课的"反直觉"结论**：独立 ⇒ 不相关，但不相关 ⇏ 独立；期望线性性不需要独立性（CS70 最重要的解题杠杆）；样本均值 23 人就有 50% 生日碰撞（生日悖论）；有限域上 n+1 个点唯一确定 ≤ n 次多项式（秘密共享的根基）。

**一句话**：CS70 教的不是公式，而是"让结论无可辩驳"的能力——离散部分管"必然成立"，概率部分管"在多大程度上成立"。

# 第一部分：离散数学

## 1. 命题逻辑与量词

- **命题**：非真即假的陈述。`∧`（且）、`∨`（或）、`¬`（非）、`⇒`（蕴含）、`⇔`（等价）。
- **蕴含真值表**：`P ⇒ Q` 仅在 P 真 Q 假时为假；P 为假时恒真（"空真"）。
- **三个等价变换**（证明题反复用）：
  - 逆否等价：`P ⇒ Q` ≡ `¬Q ⇒ ¬P`
  - 蕴含展开：`P ⇒ Q` ≡ `¬P ∨ Q`
  - 德摩根：`¬(P ∧ Q)` ≡ `¬P ∨ ¬Q`；量词版 `¬∀x P(x)` ≡ `∃x ¬P(x)`
- **量词顺序敏感**：`∀x ∃y` 与 `∃y ∀x` 含义不同（"每个人都有一个母亲" ≠ "有一个人是所有人的母亲"）。
- **易错**：证明"对所有 x 成立"必须取任意 x 推理；否定它只需一个反例。

## 2. 证明方法选择决策树

```
要证 P ⇒ Q，选哪条路？
│
├─ P 的结构好直接展开？
│    └─> 直接证明：假设 P，推导 Q
│
├─ Q 是"不存在 / 唯一 / 无限"类否定结构？
│    └─> 反证法：假设 P ∧ ¬Q，推出矛盾
│
├─ Q 本身比 P 简单？
│    └─> 逆否证明：假设 ¬Q，推导 ¬P
│
├─ 要证"存在 x 使 P(x)"？
│    └─> 构造法：显式给出 x（强于非构造证明）
│
└─ 对象是自然数 / 递归结构（树、序列、图）？
     └─> 归纳法（见第 3 节）
```

- **反证 vs 逆否的区别**：逆否只假设 ¬Q，目标 ¬P，是直接证明；反证假设 P ∧ ¬Q，目标任意矛盾。能用逆否就别用反证（更清晰）。
- **构造法的威力**：证明存在性时，"我给你看一个"永远比"假设不存在则矛盾"更有信息量。

## 3. 归纳法（CS70 看家工具）

### 普通归纳模板
1. **Base**：验证 P(n₀)（通常 n=0 或 1）。
2. **归纳假设 IH**：假设 P(k) 成立。
3. **归纳步骤**：由 P(k) 推出 P(k+1)。

### 强归纳模板
- IH 假设 **P(n₀) ∧ P(n₀+1) ∧ ... ∧ P(k)** 全部成立，再推 P(k+1)。
- **何时需要强归纳**：递推依赖前若干项而非仅前一项（如斐波那契、欧几里得算法、硬币问题）。
- 普通归纳、强归纳、良序原理三者逻辑等价，只是形式选择。

### 归纳法常见失败模式
- Base 没验证或取错起点（"所有马同色"悖论的根源）。
- 归纳步骤偷偷用了比 IH 更强的结论。
- 从 n=1 推 n=2 时隐含假设不成立（经典悖论就利用这一步缺口）。
- 对实数 / 图等非自然数结构硬套归纳——需要先定义递归结构（如对顶点数归纳）。

## 4. 稳定匹配（Gale-Shapley）

- **问题**：n 男 n 女各有偏好序，求一个"稳定"完美匹配——不存在一对男女互相觉得对方比当前伴侣好（blocking pair）。
- **算法**：propose-dispose 循环——未婚男性向偏好表上下一位女性求婚；女性暂时接受更好的、拒绝更差的；被拒男性继续向次位求婚。
- **四个核心定理**（考试要求会证）：
  1. 算法必终止（每个男性的求婚列表严格递减，有限步内耗尽）。
  2. 终止时是完美匹配（终止时若有男性未婚，则必有女性未婚，但男性求过所有女性且未被……推出矛盾）。
  3. 匹配稳定（任何 blocking pair 中，男性必向该女性求过婚并被拒，说明她当时有更好的，最终只会更好）。
  4. **男性最优 / 女性最劣**：在所有稳定匹配中，每位男性得到的是他能得到的最好女性，每位女性得到的是她能得到的最差男性。
- **直觉**：主动方获得最优解。交换求婚方性别，结论整体反转。

## 5. 图论基础

- **基本量**：度数、路径、连通分量；**握手引理**：∑deg(v) = 2|E|（推论：奇度顶点数为偶数）。
- **树的四个等价命题**（任两条可互推）：连通无环 / 连通且 |E|=|V|−1 / 无环且 |E|=|V|−1 / 任意两点间唯一简单路径。
- **欧拉回路**：经过每条边恰一次的闭合路径；判据：连通且**所有顶点度数为偶数**。欧拉路径：恰两个奇度顶点。
- **哈密顿问题**：经过每个顶点恰一次——无简单判据，是 NP 完全问题（与欧拉形成对比：边易顶点难）。
- **二分图**：顶点可二染色 ⇔ 不含奇环；完全二分图 K_{m,n}。
- **邻接矩阵**：A^k 的 (i,j) 元素 = 从 i 到 j 长度为 k 的路径数（计数题利器）。

## 6. 数论与模运算

- **同余**：`a ≡ b (mod m)` 当且仅当 m | (a−b)；同余保持加减乘。
- **GCD 与欧几里得算法**：`gcd(a,b) = gcd(b, a mod b)`，直到余数 0。
- **贝祖等式**：存在 x, y 使 `ax + by = gcd(a,b)`；用**扩展欧几里得**反向回代求出。
- **模逆元**：当且仅当 `gcd(a,m)=1` 时，a 在 mod m 下有唯一逆元 a⁻¹；求法：贝祖给出 ax + km = 1，则 x 即逆元。
- **费马小定理**：p 为素数且 p ∤ a 时，`a^(p−1) ≡ 1 (mod p)`；推论 `a⁻¹ ≡ a^(p−2) (mod p)`。
- **欧拉定理**：推广版 `a^φ(m) ≡ 1 (mod m)`（gcd(a,m)=1）；φ(m) 是欧拉函数。
- **中国剩余定理 CRT**：若模数两两互素，模乘积下的同余方程组有唯一解——RSA 加速与大数计算的基础。

## 7. RSA 全流程（必须能默写并证明）

1. **密钥生成**：选两个大素数 p, q；n = pq；φ(n) = (p−1)(q−1)；选 e 使 gcd(e, φ(n)) = 1；求 d = e⁻¹ mod φ(n)。公钥 (e, n)，私钥 (d, n)。
2. **加密**：c = m^e mod n。
3. **解密**：m = c^d mod n。
4. **正确性证明骨架**：
   - ed ≡ 1 (mod φ(n))，即 ed = 1 + kφ(n)。
   - c^d = m^(ed) = m · (m^φ(n))^k ≡ m (mod n)，最后一步对 gcd(m,n)=1 用欧拉定理；m 与 n 不互素的边界情况用 CRT 分 mod p、mod q 单独验证。
5. **安全性直觉**：加密只依赖 n, e（公开），解密需要 d，求 d 等价于分解 n——大数分解没有已知多项式算法。

## 8. 多项式与秘密共享

- **系数域**：一切在有限域 GF(p)（p 素数）上进行，除法用模逆元。
- **插值唯一性定理**：deg ≤ d 的多项式由 d+1 个不同点的取值唯一确定。
  - 证明骨架：两点对 (P−Q) 有 d+1 个根，但 deg(P−Q) ≤ d；非零 d 次多项式至多 d 个根 ⇒ P−Q ≡ 0。
- **Shamir 秘密共享**：秘密 S 作为常数项，随机选 deg ≤ t−1 多项式 P，给 n 人各发一个点 (i, P(i))。
  - ≥ t 人：插值唯一恢复 P，得 S。
  - < t 人：任何 S 都能补出某条与已知点相容的多项式——**信息论意义上零泄露**（不只是"算不出来"）。
- **纠错码思想**：编码用次数有界的多项式，传输中少量错误时，靠"真实点数多于确定多项式所需"恢复，Berlekamp-Welch 完成定位。

# 第二部分：计数与概率

## 9. 计数工具

- **加法法则**（互斥分类）、**乘法法则**（分步独立选择）。
- **鸽巢原理**：n+1 个物体放 n 个盒子，至少一盒 ≥ 2；推广：n 个放 k 盒，至少一盒 ≥ ⌈n/k⌉。
- **容斥原理**：|A∪B| = |A|+|B|−|A∩B|；三集合及以上交替加减。
- **排列组合**：P(n,k) = n!/(n−k)!；C(n,k) = n!/(k!(n−k)!)。
- **二项式定理**：(x+y)^n = Σ C(n,k) x^k y^(n−k)。
- **生日悖论计算范式**：n 人中至少两人生日相同 = 1 − (365/365)(364/365)…((365−n+1)/365)；n≈23 时即超 50%。碰撞在 √N 量级显著，这是哈希表 / 短链 / 随机 token 设计的量化基础。

## 10. 概率空间与条件概率

- **概率三公理**：非负性；P(Ω)=1；可数可加性（互斥事件并的概率等于概率之和）。
- **条件概率**：P(A|B) = P(A∩B)/P(B)。
- **全概率公式**：按划分 B₁…B_k 拆分，P(A) = Σ P(A|B_i)P(B_i)。
- **贝叶斯公式**：P(B|A) = P(A|B)P(B) / P(A)——由"证据下的似然"反推"原因的概率"。
- **独立性**：P(A∩B) = P(A)P(B)；三事件相互独立要求两两独立 **且** P(A∩B∩C)=P(A)P(B)P(C)，条件不能省。
- **易错**：互斥（交集为空）与独立（交集概率等于乘积）是两个概念；两个正概率事件若互斥则必不独立。

## 11. 随机变量与分布

- **随机变量**：样本空间到实数的函数；离散用 PMF，连续用 PDF，统一用 CDF。
- **期望**：E[X] = Σ x·P(X=x)（离散）/ ∫ x·f(x)dx（连续）。
- **期望线性性**（全课最强杠杆）：**E[aX+bY] = aE[X]+bE[Y]，无任何独立要求**。
- **指示变量法**：把复杂计数 X 拆成 X = I₁+…+I_n（I_k 是 0/1 变量），则 E[X] = Σ P(事件 k)——期望线性性的标准应用姿势（求"期望有多少人拿到自己帽子""期望多少生日碰撞"）。
- **独立性 ⇒ E[XY]=E[X]E[Y]**，但反过来不成立。
- **方差**：Var(X) = E[(X−E[X])²] = E[X²]−(E[X])²；Var(aX+b) = a²Var(X)。
- **独立时方差可加**：Var(X+Y) = Var(X)+Var(Y)（不独立要加 2Cov）。
- **协方差与相关系数**：Cov(X,Y) = E[XY]−E[X]E[Y]；ρ ∈ [−1,1] 只衡量线性关系；独立 ⇒ ρ=0，ρ=0 ⇏ 独立。

## 12. 重要分布速查

| 分布 | 模型 | PMF / PDF | 期望 | 方差 |
|---|---|---|---|---|
| Bernoulli(p) | 一次成败 | 1 概率 p，0 概率 1−p | p | p(1−p) |
| Binomial(n,p) | n 次独立成败的成功数 | C(n,k)p^k(1−p)^(n−k) | np | np(1−p) |
| Geometric(p) | 首次成功所需次数 | (1−p)^(k−1)p | 1/p | (1−p)/p² |
| Poisson(λ) | 稀有事件计数（近似二项） | e⁻λ λ^k/k! | λ | λ |
| Uniform(a,b) | 区间等可能 | 1/(b−a) | (a+b)/2 | (b−a)²/12 |
| Exponential(λ) | 无记忆等待时间 | λe^(−λx) | 1/λ | 1/λ² |
| Normal(μ,σ²) | 大量独立扰动之和 | — | μ | σ² |

- **无记忆性**：几何（离散）与指数（连续）独有——P(X>s+t | X>s) = P(X>t)。
- **二项 → 泊松**：n 大 p 小、np 适中时近似。
- **二项 → 正态**：np 与 n(1−p) 都大时用 CLT 近似（±0.5 连续性修正）。

## 13. 不等式与极限定理

- **Markov 不等式**（只需非负 + 期望）：P(X ≥ a) ≤ E[X]/a。弱，但无分布假设时唯一可用。
- **Chebyshev 不等式**（需期望 + 方差）：P(|X−μ| ≥ a) ≤ σ²/a²。
  - 应用于样本均值：P(|X̄−μ| ≥ ε) ≤ σ²/(nε²)——样本量平方级压低偏差概率。
- **大数定律 LLN**：i.i.d. 样本均值依概率（甚至几乎必然）收敛到期望——频率学派的理论根据。
- **中心极限定理 CLT**：i.i.d.、期望方差有限时，(X̄−μ)/(σ/√n) 收敛到标准正态——无论原分布长什么样。
- **层级关系**：Markov（信息最少、界最弱）→ Chebyshev（多一个方差信息）→ CLT（分布形态都近似出来）；数据科学估计置信区间靠后两者。

## 14. 马尔可夫链（进阶概念）

- **定义**：离散状态 + 转移矩阵 P，满足无记忆性 P(X_{n+1}|X_n,…,X_0) = P(X_{n+1}|X_n)。
- **稳态分布 π**：π = πP（行向量）；不可约 + 非周期链收敛到唯一 π。
- **细致平衡**：π(i)P(i,j) = π(j)P(j,i) 对所有 i,j 成立 ⇒ π 是稳态（检验稳态的捷径，不必解方程组）。
- **应用直觉**：服务状态（健康 / 降级 / 故障）转移、PageRank、随机算法分析。

## 15. 推断与回归

- **点估计**：样本均值估计总体期望；无偏性 E[X̄] = μ。
- **置信区间**：CLT 给 μ 的近似 95% 区间 X̄ ± 1.96σ/√n——正确解读是"重复抽样中 95% 的区间覆盖真值"，不是"真值以 95% 概率落在区间内"。
- **线性回归**：拟合 ŷ = ax+b，最小化均方误差；对平方损失求导得闭式解（a = Cov(x,y)/Var(x)）；最小二乘是投影思想。

## 证明方法速查卡

| 要证的结论形态 | 首选武器 |
|---|---|
| 对所有自然数成立 | 归纳 / 强归纳 |
| 不存在某物 | 反证 |
| A ⇒ B，B 是否定式 | 逆否 |
| 存在性 | 构造法 |
| 唯一性 | 假设两个，证明相等（多项式插值、模逆元、Gale-Shapley 匹配都用此套路） |
| 无限多个（如素数无限） | 反证 + 构造新对象 |
| 图 / 树 / 序列性质 | 对顶点数 / 边数 / 长度归纳 |
| 期望（不要求独立） | 指示变量 + 期望线性性 |
| 尾概率上界 | Markov（知期望）→ Chebyshev（知方差）→ CLT（知近似分布） |
| 至少 / 不少于 | 鸽巢原理、期望论证（若 E[X]>k 则存在 X>k 的情形） |

## 期望论证（Probabilistic Method 雏形）

- 套路：要证"存在一个对象具有性质 P"，构造随机对象 X，证明 E[指标_P] > 0，则必有某个对象满足 P。
- 案例：证明某种图必然存在、Ramsey 数下界。不给出构造，但存在性无可辩驳。

## 方法论卡片

### 卡片 A：做证明题的标准流程
1. 把条件和结论分别形式化（写清论域、量词、前提集合）。
2. 判断结论类型（全称 / 存在 / 唯一 / 否定），对照速查卡选武器。
3. 在草稿纸上反向推导（从结论倒推需要什么），再正向誊写。
4. 检查：每一步是否引用了定义或已证结论？归纳是否验证了 base 且归纳步骤只用了合法 IH？

### 卡片 B：概率建模三步
1. 定义样本空间 Ω（所有可能结局）并确认等可能性或给出概率测度。
2. 把题目事件翻译成 Ω 的子集；复合事件用 ∩、∪、条件表示。
3. 需要数值时定义随机变量，优先判断能否套成熟分布（Bernoulli/Binomial/…），再用线性性 / 条件期望求解。

### 卡片 C：计数不重不漏检查
- 先问：我是在给"什么东西"计数？每个结局被数了几次？
- 分类后用加法法则必须保证类别互斥且并集完备。
- 有序用排列、无序用组合；看到"至少一个"先想补集（1−全不发生）。
- 算完用小数字 n=1,2,3 手工枚举验证公式。

### 卡片 D：RSA / 数论题的解题顺序
1. 化简模数（CRT 拆分或直接代同余性质）。
2. 指数用费马 / 欧拉降幂：先把指数 mod (p−1) 或 φ(n)。
3. 需要除法时先求逆元（扩展欧几里得或费马 a^(p−2)）。
4. 证明题回到贝祖等式——gcd=1 是几乎所有"存在逆元 / 存在解"结论的根源。

### 卡片 E：极限定理选择题
```
要估计 P(X ≥ a)，已知多少信息？
├─ 只知 E[X]，X 非负           → Markov
├─ 知 E[X] 和 Var(X)           → Chebyshev
├─ X 是大量 i.i.d. 之和/均值   → CLT 转标准正态
└─ 求样本量 n 保证误差概率      → Chebyshev 保守界 / CLT 精确近似
```

## 学习路径建议

1. **证明先行**：前两周死磕逻辑 + 四种证明法 + 归纳，后续所有内容都在复用这套语言；归纳不熟，数论和多项式全卡。
2. **数论一条线打通**：整除 → GCD → 贝祖 → 逆元 → 费马 → RSA，每一步都问"上一步给了我什么才能推出这一步"；能手算小素数 RSA 全流程算过关。
3. **概率部分抓住两个杠杆**：期望线性性（配指示变量）+ 条件概率 / 全概率；80% 的概率题靠这两个。
4. **不等式与 CLT 是收尾重点**：理解"信息越多，界越紧"的层级，而不是背三个公式。
5. **刷题方式**：每道证明题先合上书自己写完整证明，再对答案抠"哪一步我跳了"——CS70 扣分几乎都在跳步，不在结论错。
