### 🧠 链表核心知识点

- **单链表结构**：节点只存 `val` + `next`，无前驱信息
- **删除策略**：
  - ❌ 不能直接删除当前节点（找不到前驱）
  - ✅ 让 `cur` 站在前驱位置，操作 `cur.next`
  - ✅ 或使用 dummy 虚拟头结点
- **dummy 头结点**：
  - 价值：消除头结点特殊情况，统一逻辑
  - 使用场景：几乎所有链表题目

## 三、高频算法模板

### 1. 滑动窗口模板

```python
def sliding_window(nums, target):
    left = 0
    total = 0
    result = float("inf")
    
    for right in range(len(nums)):
        total += nums[right]  # 扩展窗口
        
        while total >= target:  # 收缩窗口
            result = min(result, right - left + 1)
            total -= nums[left]
            left += 1
    
    return result if result != float("inf") else 0
```

### 2. 链表 dummy 模板

```python
def remove_elements(head, val):
    dummy = ListNode(0, next=head)
    cur = dummy
    
    while cur.next:
        if cur.next.val == val:
            cur.next = cur.next.next
        else:
            cur = cur.next
    
    return dummy.next
```
