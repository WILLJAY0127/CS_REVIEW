# 704. 二分查找

## 📌 题目链接

[力扣题目链接](https://leetcode.cn/problems/binary-search/)

## 📋 题目描述

给定一个 n 个元素有序的（升序）整型数组 `nums` 和一个目标值 `target`，写一个函数搜索 `nums` 中的 `target`，如果目标值存在返回下标，否则返回 `-1`。

### 示例

```python
# 示例 1
输入: nums = [-1, 0, 3, 5, 9, 12], target = 9
输出: 4
解释: 9 出现在 nums 中并且下标为 4

# 示例 2
输入: nums = [-1, 0, 3, 5, 9, 12], target = 2
输出: -1
解释: 2 不存在 nums 中因此返回 -1
```

### 提示

- `nums` 中的所有元素是不重复的
- `n` 将在 `[1, 10000]` 之间
- `nums` 的每个元素都将在 `[-9999, 9999]` 之间

---

## ⚠️ 二分查找的前提条件

**这是使用二分法的核心前提，必须牢记！**

### 条件一：数组必须是有序的

如果数组无序，二分查找就无法确定目标值在哪一边，算法直接失效。

### 条件二：数组中无重复元素

如果数组中有重复元素，二分查找返回的下标可能不是唯一的。

**识别技巧**：当题目描述满足以上两个条件时，一定要想到二分法！

---

## 🎯 为什么二分法难写？

二分查找的逻辑很简单，但边界条件非常容易出错：

- 到底是 `while(left < right)` 还是 `while(left <= right)`？
- 到底是 `right = middle` 还是 `right = middle - 1`？

**核心原因**：对区间的定义没有想清楚！

---

## 🧠 循环不变量规则（核心！）

**区间的定义就是不变量。**

在二分查找的过程中，保持不变量，就是在 `while` 寻找中每一次边界的处理都要坚持根据区间的定义来操作。

**写二分法的关键**：
1. **先明确区间的定义**（左闭右闭 vs 左闭右开）
2. **然后严格按照区间定义来写代码**

两种区间定义对应两种不同的写法，下面分别讲解。

---

## 📐 区间定义一：左闭右闭 [left, right]

### 区间特点

- 左边界 `left`：包含在区间内
- 右边界 `right`：包含在区间内
- 数组下标本身就是 `[0, len(nums)-1]`，和闭区间天然匹配

### 推导过程

#### 第一步：初始化边界

```python
left = 0
right = len(nums) - 1  # 右边界是数组最后一个元素的下标
```

#### 第二步：确定循环条件

```python
while left <= right:  # 因为是闭区间，left == right 时还有一个元素需要检查
```

**为什么是 `<=`？**
- 当 `left == right` 时，区间 `[left, right]` 中还有一个元素
- 如果用 `<`，会漏掉这个元素

#### 第三步：更新边界

```python
mid = left + (right - left) // 2  # 防止溢出

if nums[mid] == target:
    return mid          # 找到！返回下标
elif nums[mid] < target:
    left = mid + 1      # 目标在右半部分，mid 已检查过，排除
else:
    right = mid - 1     # 目标在左半部分，mid 已检查过，排除
```

**为什么 `right = mid - 1`？**
- 因为 `nums[mid]` 已经不等于 `target`
- 区间是闭的，`mid` 不需要再检查，所以排除

### 完整代码

```python
def search(nums, target):
    left = 0
    right = len(nums) - 1  # 左闭右闭：右边界是数组最后一个元素
    
    while left <= right:   # 左闭右闭：区间不为空的条件
        mid = left + (right - left) // 2  # 防止溢出
        
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1  # 目标在右半部分，排除 mid
        else:
            right = mid - 1  # 目标在左半部分，排除 mid
    
    return -1  # 未找到
```

## 📐 区间定义二：左闭右开 [left, right)

### 区间特点

- 左边界 `left`：包含在区间内
- 右边界 `right`：**不包含**在区间内
- 右边界初始值是数组长度

### 推导过程

#### 第一步：初始化边界

```python
left = 0
right = len(nums)  # 右边界是数组长度（不包含）
```

#### 第二步：确定循环条件

```python
while left < right:  # 因为是开区间，left == right 时区间为空
```

**为什么是 `<`？**
- 当 `left == right` 时，区间 `[left, right)` 是空的
- 没有元素需要检查

#### 第三步：更新边界

```python
mid = left + (right - left) // 2

if nums[mid] == target:
    return mid
elif nums[mid] < target:
    left = mid + 1      # 目标在右半部分，mid 已检查过，排除
else:
    right = mid         # 目标在左半部分，右开区间，mid 不包含在内，所以不用减1
```

**为什么 `right = mid`？**
- 因为右边界是开的，`right` 指向的元素本身就不在区间内
- `nums[mid]` 已经不等于 `target`，所以把 `right` 设为 `mid` 就排除了它

### 完整代码

```python
def search(nums, target):
    left = 0
    right = len(nums)  # 左闭右开：右边界是数组长度（不包含）
    
    while left < right:  # 左闭右开：区间不为空的条件
        mid = left + (right - left) // 2
        
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1  # 目标在右半部分，排除 mid
        else:
            right = mid     # 目标在左半部分，右开区间，mid 不包含在内
    
    return -1
```

---

## 📝 两种区间定义对比

| 区间定义 | 左边界 | 右边界 | 循环条件 | 更新方式 |
|----------|--------|--------|----------|----------|
| **左闭右闭** `[left, right]` | `left = 0` | `right = len(nums) - 1` | `left <= right` | `right = mid - 1` / `left = mid + 1` |
| **左闭右开** `[left, right)` | `left = 0` | `right = len(nums)` | `left < right` | `right = mid` / `left = mid + 1` |

## 🧠 从题目到代码的思考过程

#### 第一步：分析题目特征

```
题目：给定有序数组 nums 和目标值 target，查找 target 的下标
```

- ✅ 数组有序 → 符合二分查找的前提条件
- ✅ 元素不重复 → 可以唯一确定目标位置
- ❓ 目标值可能不存在 → 需要处理未找到的情况

#### 第二步：选择区间定义

**推荐选择左闭右闭 `[left, right]`**：
- 最直观，符合日常思维习惯
- 和数组下标天然匹配

#### 第三步：推导核心逻辑

按照区间定义，逐步写出代码：
1. 初始化边界
2. 确定循环条件
3. 更新边界
4. 处理未找到的情况

#### 第四步：验证边界情况

| 边界情况 | 测试用例 | 预期结果 |
|----------|----------|----------|
| 目标在数组开头 | `nums=[1,3,5], target=1` | 返回 0 |
| 目标在数组末尾 | `nums=[1,3,5], target=5` | 返回 2 |
| 目标不存在 | `nums=[1,3,5], target=2` | 返回 -1 |
| 数组只有一个元素 | `nums=[5], target=5` | 返回 0 |
| 数组只有一个元素且不存在 | `nums=[5], target=3` | 返回 -1 |

## 🔄 递归实现

```python
def search(nums, target):
    def helper(left, right):
        if left > right:  # 区间为空
            return -1
        
        mid = left + (right - left) // 2
        
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            return helper(mid + 1, right)
        else:
            return helper(left, mid - 1)
    
    return helper(0, len(nums) - 1)
```

---

## ⚠️ 常见错误

| 错误 | 原因 | 解决方法 |
|------|------|----------|
| `mid = (left + right) // 2` 溢出 | 当 left 和 right 都很大时，和可能超出整数范围 | 改用 `mid = left + (right - left) // 2` |
| 循环条件写成 `left < right` | 对于左闭右闭区间，会漏掉最后一个元素 | 改为 `left <= right` |
| 更新 `right = mid` 或 `left = mid` | 可能导致死循环 | 根据区间定义正确更新 |

## 🔌 接口抽象：从具体到通用

学习二分查找不应该只停留在"能做题"的层面，而要理解其**通用模式**。

### 通用二分查找接口

```python
def binary_search(arr, condition, left=0, right=None):
    """
    通用二分查找接口
    
    参数:
        arr: 待查找的数组
        condition: 判断函数，接收索引，返回 True/False
        left: 左边界（默认0）
        right: 右边界（默认数组长度）
    
    返回:
        满足 condition 的第一个位置
    """
    if right is None:
        right = len(arr)
    
    while left < right:
        mid = left + (right - left) // 2
        if condition(mid):
            right = mid
        else:
            left = mid + 1
    
    return left
```

### 使用示例

#### 示例一：查找第一个大于等于 target 的位置

```python
def find_first_ge(nums, target):
    """找到第一个 >= target 的位置"""
    def condition(mid):
        return nums[mid] >= target
    return binary_search(nums, condition)

# 使用
nums = [1, 3, 5, 7, 9]
print(find_first_ge(nums, 5))   # → 2
print(find_first_ge(nums, 4))   # → 2
print(find_first_ge(nums, 10)) # → 5（超出范围）
```

#### 示例二：查找最后一个小于等于 target 的位置

```python
def find_last_le(nums, target):
    """找到最后一个 <= target 的位置"""
    def condition(mid):
        return nums[mid] > target
    result = binary_search(nums, condition)
    return result - 1 if result > 0 else -1

# 使用
nums = [1, 3, 5, 7, 9]
print(find_last_le(nums, 5))  # → 2
print(find_last_le(nums, 6))  # → 2
print(find_last_le(nums, 0))  # → -1（未找到）
```

#### 示例三：查找值的精确位置

```python
def find_exact(nums, target):
    """精确查找 target 的位置"""
    pos = find_first_ge(nums, target)
    if pos < len(nums) and nums[pos] == target:
        return pos
    return -1

# 使用
nums = [1, 3, 5, 7, 9]
print(find_exact(nums, 5))  # → 2
print(find_exact(nums, 4))  # → -1
```

## 🏗️ 设计模式：策略模式

上面的 `condition` 函数就是**策略模式**的体现：

| 接口层 | 策略层 | 结果 |
|--------|--------|------|
| `binary_search(arr, condition)` | `lambda mid: nums[mid] >= target` | 找第一个 ≥ target |
| `binary_search(arr, condition)` | `lambda mid: nums[mid] > target` | 找第一个 > target |
| `binary_search(arr, condition)` | `lambda mid: nums[mid] == target` | 找精确位置 |

### 优点

1. **分离关注点**：二分逻辑和查找策略解耦
2. **可扩展性**：新增查找需求只需实现新的 condition
3. **可测试性**：接口和策略可以独立测试

## 📐 二分查找的变体问题

理解了接口抽象后，来看看常见的二分变体：

### 变体一：查找左边界

```python
def find_left_bound(nums, target):
    """找到 target 的左边界（第一个等于 target 的位置）"""
    left, right = 0, len(nums)
    while left < right:
        mid = left + (right - left) // 2
        if nums[mid] >= target:
            right = mid
        else:
            left = mid + 1
    return left if left < len(nums) and nums[left] == target else -1
```

### 变体二：查找右边界

```python
def find_right_bound(nums, target):
    """找到 target 的右边界（最后一个等于 target 的位置）"""
    left, right = 0, len(nums)
    while left < right:
        mid = left + (right - left) // 2
        if nums[mid] > target:
            right = mid
        else:
            left = mid + 1
    return left - 1 if left > 0 and nums[left - 1] == target else -1
```

### 变体三：搜索旋转数组

```python
def search_rotated(nums, target):
    """搜索旋转排序数组中的目标值"""
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        # 判断哪一部分有序
        if nums[left] <= nums[mid]:
            # 左半部分有序
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        else:
            # 右半部分有序
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1
    return -1
```

## 📝 总结

### 三层理解二分查找

| 层次 | 内容 | 目标 |
|------|------|------|
| **L1 实现层** | 左闭右闭、左闭右开两种写法 | 能正确写出代码 |
| **L2 抽象层** | 通用接口 + 策略模式 | 理解设计模式 |
| **L3 应用层** | 数据库、配置、时序分析 | 解决实际问题 |

### 核心要点

1. **明确区间定义**：左闭右闭 `[left, right]` 或左闭右开 `[left, right)`
2. **保持循环不变量**：每次边界处理都要坚持根据区间的定义来操作
3. **理解通用模式**：condition 函数是策略模式的体现
4. **掌握常见变体**：左边界、右边界、旋转数组
