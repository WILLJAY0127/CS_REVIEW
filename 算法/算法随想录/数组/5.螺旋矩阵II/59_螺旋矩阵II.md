# LeetCode 59 - 螺旋矩阵 II

## 核心精髓：循环不变量（统一区间规则）

**题目难点不是算法，是模拟边界。**

很多人写崩的根源：四条边遍历规则不统一，一条左闭右闭、一条左闭右开，拐角元素重复赋值/漏赋值。

### 选定规则

每条边统一采用 **【左闭右开 [start, end)】**

- 拐角交给下一条边处理，不重复处理交点
- 填充顺序（由外向内一圈一圈）：
  1. 上行：左 → 右
  2. 右列：上 → 下
  3. 下行：右 → 左
  4. 左列：下 → 上

---

## 变量定义

| 变量 | 含义 |
|------|------|
| `startx, starty` | 当前圈左上角起点坐标 |
| `offset` | 控制每一条边收缩长度（每向内一圈 offset+1） |
| `loop` | 一共要循环多少圈 |
| `mid` | n 为奇数时，矩阵中心点下标，最后单独填中间数字 |
| `num` | 待填入矩阵的值，从 1 增长到 n² |

---

## 数学规律

### 循环圈数

`loop = n // 2`

- `n=3` → `loop=1`（外围一圈，剩下中心单独填 9）
- `n=4` → `loop=2`（完整两圈，无中心点）

## 思路 1：分层圈写法（左闭右开标准）

### Python 代码实现

```python
from typing import List

def generateMatrix(n: int) -> List[List[int]]:
    res = [[0] * n for _ in range(n)]
    startx, starty = 0, 0
    loop = n // 2
    offset = 1
    num = 1
    mid = n // 2

    while loop > 0:
        i, j = startx, starty

        # 1. 上行：左 -> 右  [starty, n-offset)
        for j in range(starty, n - offset):
            res[i][j] = num
            num += 1
        
        # 2. 右列：上 -> 下 [startx, n-offset)
        for i in range(startx, n - offset):
            res[i][j] = num
            num += 1
        
        # 3. 下行：右 -> 左 [n-offset, starty)
        for j in range(n - offset, starty, -1):
            res[i][j] = num
            num += 1
        
        # 4. 左列：下 -> 上 [n-offset, startx)
        for i in range(n - offset, startx, -1):
            res[i][j] = num
            num += 1

        # 向内收缩一圈
        startx += 1
        starty += 1
        offset += 1
        loop -= 1
    
    # n是奇数，填充中心点
    if n % 2 == 1:
        res[mid][mid] = num
    return res
```

- **时间复杂度**：O(n²)（模拟遍历二维矩阵的时间）
- **空间复杂度**：O(1)（不计输出矩阵）

### C++ 版本（标准模板）

```cpp
class Solution {
public:
    vector<vector<int>> generateMatrix(int n) {
        vector<vector<int>> res(n, vector<int>(n, 0));
        int startx = 0, starty = 0;
        int loop = n / 2;
        int mid = n / 2;
        int count = 1;
        int offset = 1;
        int i, j;
        
        while (loop--) {
            i = startx;
            j = starty;

            // 上行从左到右(左闭右开)
            for (j; j < n - offset; j++) {
                res[i][j] = count++;
            }
            // 右列从上到下(左闭右开)
            for (i; i < n - offset; i++) {
                res[i][j] = count++;
            }
            // 下行从右到左(左闭右开)
            for (; j > starty; j--) {
                res[i][j] = count++;
            }
            // 左列从下到上(左闭右开)
            for (; i > startx; i--) {
                res[i][j] = count++;
            }

            startx++;
            starty++;
            offset += 1;
        }

        if (n % 2) {
            res[mid][mid] = count;
        }
        return res;
    }
};
```

## 样例推演 n=3

### 输出

```
[[1, 2, 3],
 [8, 9, 4],
 [7, 6, 5]]
```

### 逐圈推演

**初始状态**：`loop=1, startx=0, starty=0, offset=1, num=1`

| 步骤 | 操作 | 循环范围 | 填充结果 | 说明 |
|------|------|---------|---------|------|
| 1 | 上行 | `j: 0→1` (左闭右开，不到 2) | `res[0][0]=1, res[0][1]=2` | j 最终=1 |
| 2 | 右列 | `i: 0→1` | `res[0][1]=3, res[1][1]=4` | i 最终=1 |
| 3 | 下行 | `j: 1→0` | `res[1][1]=5, res[1][0]=6` | j 最终=0 |
| 4 | 左列 | `i: 1→0` | `res[1][0]=7, res[0][0]=8` | i 最终=0 |

**一圈结束**：`startx=1, starty=1, offset=2, loop=0` → 退出循环

**n 为奇数**：填充中心点 `res[1][1]=9`

### 可视化矩阵状态变化

```
步骤1后:  [1, 2, 0]    步骤2后:  [1, 2, 3]
          [0, 0, 0]              [0, 0, 4]
          [0, 0, 0]              [0, 0, 0]

步骤3后:  [1, 2, 3]    步骤4后:  [1, 2, 3]
          [6, 5, 4]              [8, 9, 4]  ← 中心点最后填9
          [0, 0, 0]              [7, 6, 5]
```

## 思路 2：方向模拟（备选写法）

### 核心思路

设置四个方向 → 右→下→左→上，碰壁或者遇到非 0 数字就换向。

### Python 代码实现

```python
from typing import List

def generateMatrix(n: int) -> List[List[int]]:
    matrix = [[0] * n for _ in range(n)]
    # 方向：右、下、左、上
    dirs = [(0, 1), (1, 0), (0, -1), (-1, 0)]
    x, y = 0, 0
    d = 0
    
    for num in range(1, n * n + 1):
        matrix[x][y] = num
        nx = x + dirs[d][0]
        ny = y + dirs[d][1]
        
        # 越界 或者 已经填过数字，换向
        if nx < 0 or nx >= n or ny < 0 or ny >= n or matrix[nx][ny] != 0:
            d = (d + 1) % 4
            nx = x + dirs[d][0]
            ny = y + dirs[d][1]
        
        x, y = nx, ny
    
    return matrix
```

### 两种思路对比

| 对比项 | 分层圈写法 | 方向模拟 |
|--------|----------|---------|
| 实现方式 | 按圈拆分、四条边分段填充 | 一步一格持续走，自动换向 |
| 复杂度 | O(n²) | O(n²) |
| 优点 | 规则统一，逻辑清晰 | 代码简短，直觉性强 |
| 缺点 | 需要理解循环不变量 | 需要判断边界和已填充格子 |
| 适用 | 标准解法，推荐掌握 | 备选方案，理解即可 |

## 三个核心问题深度解答

### 问题 1：这题有没有暴力解法？

**结论：不存在传统意义上"暴力枚举"的解法。**

- 原因：题目要求按照顺时针螺旋路径依次填充数字，没有一组可以枚举的候选方案，数字顺序由固定行走路径唯一决定。
- 很多人误以为的"暴力"：不断判断下一步能不能走、碰到边界/已填充数字就顺时针转向。**这叫模拟行走（方向模拟），不叫暴力枚举**，是另一种模拟实现方式。

> 📌 **重点区分**：本题没有双重循环枚举类暴力；只有两种模拟路线：分层圈写法 和 方向模拟。

### 问题 2：这道题抽象成了什么处理方案？

**抽象模型：由外向内逐层剥离矩形环，对每一层矩形四条边分段遍历填充。**

#### 模型拆解

1. 整个正方形 = 多层嵌套矩形环
2. 每次处理最外层一圈；处理完成，矩形左右上下边界向内收缩
3. 重复直到所有完整环处理完毕
4. 奇数矩阵剩下中心点单独赋值

#### 本质

**区间边界模拟问题**。核心难点不是算法思想，而是维持遍历区间规则统一（循环不变量）。

#### 与二分法共同点

都依靠「不变区间规则」保证代码不出边界 bug。

### 问题 3：为什么教学选用【左闭右开】，不用左闭右闭？

**关键：左闭右闭语法上完全能写，不是不能用，只是更麻烦，更容易出错。**

#### 拐角冲突分析

假设一条矩形上边：坐标 y ∈ [0,2]（左闭右闭，n=3）

- 上边填充：`j=0,1,2`
- 终点 `j=2` 这个位置，同时又是右列第一个点
- 如果四条边全都左闭右闭：上边把 `(0,2)` 赋值；右列循环又会再次读取 `(0,2)`，同一个拐角点被两条边重复处理

#### 左闭右开方案（推荐）

- 每条边不包含终点拐角，拐角交给下一条边处理
- 上边：`[start, end)`，不处理末端拐角
- 四条边首尾自然衔接，天然没有重复点，不需要额外 -1/跳过拐角
- 规则统一，代码简洁，边界判断完全一致

#### 左闭右闭方案（不推荐）

- 每条边填充完，必须手动跳过拐角点
- 上行填充 `[start, end]`，填充结束后，起点 y 必须 +1，避免右列重复读取这个拐角
- **每一条边结束都要手动修正边界**
- 四条边都要额外写边界偏移，代码冗余，极易漏写某一处，造成重复赋值

#### 取舍总结

| 对比项 | 左闭右开 | 左闭右闭 |
|--------|---------|---------|
| 拐角处理 | 移交下一条边，无重复 | 当前边占用，需手动跳过 |
| 边界规则 | 统一，简洁 | 每条边需额外偏移 |
| 代码复杂度 | 低 | 高 |
| 适合场景 | 教学首选，建立"循环不变量"思维 | 可行但维护成本高 |

> 💡 补充：不存在"左闭右闭错误"，只是维护成本更高。代码随想录选择左闭右开是教学最优选择，用来强调"统一区间规则"这个思想。

## 高频疑问梳理

### 1. 什么是循环不变量？

四条边必须保持**一模一样的区间开闭规则**。

- 本代码全部使用 `[a, b)` 左闭右开
- 拐角点留给下一条边赋值，彻底避免重复赋值
- 如果一会左闭右闭、一会左闭右开，拐角一定会出 bug

### 2. offset 作用是什么？

**控制右边界，每往里走一圈，首尾各收缩一格。**

- 第一圈 `offset=1`，边界 `n-offset`
- 下一圈 `offset=2`，边界继续缩小

### 3. 什么时候需要单独填中心点？

**n 为奇数才有唯一中心**；偶数矩阵可以完美分成完整的环，无单独格子。

## 容易踩坑清单

| 坑点 | 说明 | 正确做法 |
|------|------|---------|
| 创建矩阵错误 | 写成 `[[0]*n]*n` 会出现行引用共享 | 使用 `[[0]*n for _ in range(n)]` |
| 四条边循环边界错 | 破坏左闭右开规则 | 严格遵循 `[start, n-offset)` 规则 |
| 忘记更新边界 | 向内收缩时忘记更新 `startx, starty, offset` | 每圈结束后统一更新 |
| 漏掉中心元素 | 奇数情况漏掉中心元素赋值 | `if n % 2 == 1` 单独处理 |
| offset 更新错误 | offset 每次 +1 而非 +2 | 记住是 `offset += 1` |

### 矩阵创建示例

```python
# ❌ 错误：行会共享引用
matrix = [[0] * n] * n

# ✅ 正确：每行独立
matrix = [[0] * n for _ in range(n)]
```

## 核心模板记忆

```python
# 螺旋矩阵模板（左闭右开）
def generateMatrix(n: int) -> List[List[int]]:
    res = [[0] * n for _ in range(n)]
    startx, starty = 0, 0
    loop = n // 2
    offset = 1
    num = 1
    mid = n // 2

    while loop > 0:
        i, j = startx, starty

        # 四条边：统一左闭右开
        for j in range(starty, n - offset):     # 上行
            res[i][j] = num; num += 1
        for i in range(startx, n - offset):     # 右列
            res[i][j] = num; num += 1
        for j in range(n - offset, starty, -1): # 下行
            res[i][j] = num; num += 1
        for i in range(n - offset, startx, -1): # 左列
            res[i][j] = num; num += 1

        startx += 1; starty += 1; offset += 1; loop -= 1

    if n % 2 == 1:
        res[mid][mid] = num
    return res
```

**关键口诀**：四条边统一左闭右开，拐角移交下一条边，奇数单独填中心。
