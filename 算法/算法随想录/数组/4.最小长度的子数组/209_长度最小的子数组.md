# LeetCode 209 - 长度最小的子数组

## 核心前提（重中之重）

**数组全部元素为正整数**，这是滑动窗口解法能生效的关键。

### 性质

- 右边界向右扩展 → 区间总和变大
- 左边界向右收缩 → 区间总和变小
- 如果存在负数，滑动窗口思路直接失效

### 目标

找连续子数组，总和 ≥ target，求最小长度；没有则返回 0

---

## 思路 1：暴力解法（理解用，大数据超时 O(n²)）

固定起点 `start`，`end` 不断往右累加，一旦和满足条件记录长度并 break。

数组上限 10^5，双层循环一定会超时，只能用来理解题意。

### 代码实现

```python
from typing import List

def minSubArrayLen(target: int, nums: List[int]) -> int:
    n = len(nums)
    min_len = float("inf")
    for start in range(n):
        total = 0
        for end in range(start, n):
            total += nums[end]
            if total >= target:
                min_len = min(min_len, end - start + 1)
                break
    return min_len if min_len != float("inf") else 0
```

- **时间复杂度**：O(n²)
- **空间复杂度**：O(1)

---

## 思路 2：滑动窗口（同向双指针，最优 O(n)）

### 核心变量

| 变量 | 含义 |
|------|------|
| `start` | 窗口左边界 |
| `end` | 窗口右边界（for 循环持续向右走，只前进不回退） |
| `total` | 当前窗口 [start, end] 的累加和 |
| `min_len` | 保存满足条件区间的最小长度 |

### 执行逻辑

1. `end` 不断向右，把 `nums[end]` 加入窗口总和
2. 当 `total ≥ target`：
   - 当前窗口合法，尝试压缩左边界寻找更短区间
   - 更新最小长度
   - 左边界右移：`total -= nums[start]; start += 1`
3. **必须用 `while`，收缩后继续判断是否依旧满足条件，不能用 `if`！**

### 标准代码

```python
from typing import List

def minSubArrayLen(target: int, nums: List[int]) -> int:
    start = 0
    total = 0
    min_len = float("inf")
    n = len(nums)
    
    for end in range(n):
        total += nums[end]
        
        # 满足条件，持续收缩左边界
        while total >= target:
            window_len = end - start + 1
            min_len = min(min_len, window_len)
            total -= nums[start]
            start += 1
    
    return min_len if min_len != float("inf") else 0
```

- **时间复杂度**：O(n)（每个元素最多被访问两次，进窗口一次、出窗口一次）
- **空间复杂度**：O(1)

## 样例推演

`target=7，nums=[2,3,1,2,4,3]`

| 步骤 | end | total 变化 | total ≥ 7? | 窗口操作 | min_len |
|------|-----|-----------|------------|---------|---------|
| 1 | 0 | 0→2 | ❌ | 继续扩展 | ∞ |
| 2 | 1 | 2→5 | ❌ | 继续扩展 | ∞ |
| 3 | 2 | 5→6 | ❌ | 继续扩展 | ∞ |
| 4 | 3 | 6→8 | ✅ | len=4, total-=2→6, start=1 | 4 |
| 5 | 4 | 6→10 | ✅ | len=4(不变), total-=3→7, start=2 | 4 |
| 5' | 4 | 7 | ✅ | len=3, total-=1→6, start=3 | 3 |
| 6 | 5 | 6→9 | ✅ | len=3(不变), total-=2→7, start=4 | 3 |
| 6' | 5 | 7 | ✅ | len=2, total-=4→3, start=5 | **2** |

**最终返回 2** ✅

## 思路 3：前缀和 + 二分（O(n log n)，备选方案）

因为全正数，前缀和数组单调递增。对每个起点，二分查找最小右端点使区间和 ≥ target。

性能次于滑动窗口，适合拓展思路。

### 代码框架

```python
from typing import List
import bisect

def minSubArrayLen(target: int, nums: List[int]) -> int:
    n = len(nums)
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i + 1] = prefix[i] + nums[i]
    
    min_len = float("inf")
    for i in range(n):
        # 二分查找使 prefix[j] - prefix[i] >= target 的最小 j
        j = bisect.bisect_left(prefix, prefix[i] + target)
        if j <= n:
            min_len = min(min_len, j - i)
    
    return min_len if min_len != float("inf") else 0
```

## 高频疑问解答

### 1. 嵌套循环为什么不是 O(n²)？

`start` 和 `end` 只会单向前进，每个元素最多被左右指针各访问一次，总操作次数 ≤ 2n，复杂度为 O(n)。

### 2. 和 LC27 快慢指针有什么区别？

| 对比项 | LC27 移除元素 | LC209 长度最小的子数组 |
|--------|--------------|----------------------|
| 窗口操作 | 只扩张窗口，不需要回缩 | 条件满足后持续收缩左边界 |
| 循环结构 | 单层 `if` | 必须用 `while` 循环收缩 |
| 本质 | 收集"好元素"到前面 | 寻找满足条件的最短连续区间 |

### 3. 什么时候不能用这套滑动窗口？

**数组包含负数、0 时不能使用。**

一旦有负数，左边界右移总和可能变大，无法保证收缩窗口不会丢失最优解。

---

## 容易踩坑点

| 坑点 | 说明 | 正确做法 |
|------|------|---------|
| 初始化错误 | 最小长度初始化为 0 会导致结果永远为 0 | 初始化为 `float("inf")` 或 `INT32_MAX` |
| 收缩逻辑 | 写成 `if` 而不是 `while`，漏掉继续压缩的机会 | 必须用 `while` 持续收缩 |
| 忽略前置条件 | 忽略数组元素全为正数的前提，错误套用模板 | 先确认数组是否全为正数 |
| 返回值处理 | 忘记判断是否找到解，直接返回 min_len | 检查 `min_len != float("inf")` |

---

## 三种思路对比总结

| 思路 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|---------|
| 暴力解法 | O(n²) | O(1) | 仅用于理解题意 |
| 滑动窗口 | O(n) | O(1) | 最优解，推荐使用 |
| 前缀和 + 二分 | O(n log n) | O(n) | 备选方案，需额外空间 |

## 核心模板记忆

```python
# 滑动窗口模板（同向双指针）
def sliding_window(nums, target):
    left = 0
    total = 0
    result = float("inf")
    
    for right in range(len(nums)):
        # 1. 扩展窗口
        total += nums[right]
        
        # 2. 收缩窗口（核心！用 while 而非 if）
        while total >= target:
            # 3. 更新答案
            result = min(result, right - left + 1)
            # 4. 收缩左边界
            total -= nums[left]
            left += 1
    
    # 5. 处理无解情况
    return result if result != float("inf") else 0
```

**关键口诀**：右扩左收，条件满足时持续收缩，用 `while` 不用 `if`。
