## 二、题意核心前提

- 链表可能有环，也可能无环
- **不能修改原链表结构**（禁止打标记、改 val、改 next 指针）
- 进阶要求：空间 O(1)

### 结构示意图

```
无环：
  3 → 2 → 0 → -4 → null（走到头结束）

有环（pos=1，入环点=节点2）：
  3 → 2 → 0 → -4
       ↑________↓
```

## 三、先建立统一认知：**对齐目标节点 = 所有解法核心**

| 题目 | 目标节点 | 指针方案本质 |
|------|---------|-------------|
| LC160 相交链 | 公共起点 c1 | 长度抹平 / 交换链表，**对齐 c1** |
| LC19 删倒数 N | 倒数第 N 个前驱 | 快慢固定差 N 步，**对齐前驱节点** |
| **LC142 环形链表 II** | **环入口点** | 快慢判环 + 同步对撞，**对齐入口点** |

> 🔑 所有链表双指针题，本质都是：设计指针移动规则，最后同时踩到目标节点。

## 思路 1：暴力解法（哈希集合 Set）✅ 能过、简单、保底

### 核心思路

环的特征 = **一定会第二次踩到同一个节点对象**。
第一次重复相遇的那个节点，就是环的入口。

### 代码（Python）

```python
from typing import Optional

class ListNode:
    def __init__(self, x):
        self.val = x
        self.next = None

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        visited = set()
        cur = head
        while cur:
            if cur in visited:      # 第二次遇见 = 环入口
                return cur
            visited.add(cur)        # 第一次见，记录
            cur = cur.next
        return None                 # 走完了也没重复 = 无环
```

### 完整模拟（有环例子）

```
链：3 → 2 → 0 → -4
         ↑________↓

cur=3   visited={3}         add
cur=2   visited={3,2}       add
cur=0   visited={3,2,0}     add
cur=-4  visited={3,2,0,-4}  add
cur=2   2 in visited ✅   → return 2（环入口）
```

### 优缺点

| 优点 | 缺点 |
|------|------|
| 🧠 人脑零推导，面试紧张也写不错 | ❌ 额外空间 O(n) |
| 不需要考虑速度差、数学公式 | 达不到「进阶 O(1) 空间」考点 |
| 链表类查找暴力通用模板（和 LC160 暴力同构） | |

> 💡 **面试策略**：如果一时推不出快慢指针公式，先写 Set 版过面试，再说「我还可以优化空间到 O(1)，用快慢指针」。
> 写完有分、再秀进阶，比卡壳强太多。

## 思路 2：快慢指针（O(1) 空间，最优考点）

### 分两步执行

```
Step 1：判环 + 找相遇点
        slow 走 1 步，fast 走 2 步
        相遇 → 有环；fast 空 → 无环

Step 2：找环入口
        新指针 p = head
        p 和 slow 同步 1 步/次
        相遇位置 = 环入口
```

### ⚠️ 最重要的易错点

> ❌ **相遇点 ≠ 入环点！**
>
> 绝大多数人第一次学都会在这里翻车。快慢只是用来证明「有环」，给定位入口提供数学条件。

---

### 核心数学推导（决定第二步怎么写）

#### 符号约定

```
   x                y
head → ── → 入环点 → ── → 快慢相遇点
                ↑              │
                └──── z ───────┘
                     (绕一圈回入环点)

x：head → 入环点 的步数
y：入环点 → 相遇点 的步数
z：相遇点 → 入环点（继续向前绕一圈）的步数
环长 = y + z
```

#### 推导过程

```
slow 走过的总路程：x + y              （slow 进去环里刚走了 y 就被追上）
fast 走过的总路程：x + y + n*(y+z)    （n 是 fast 比 slow 多绕的圈数，最少 n=1）

fast 速度 = 2 * slow 速度
⇒ 2 * (x + y) = x + y + n*(y+z)
化简：
    x + y = n*(y+z)
取最常见情况 n = 1（fast 只多绕 1 圈就追上）
    x + y = y + z
    x = z
```

**✅ 核心结论（必须记住）：**

```
x = z

head → 入环点的距离  ==  相遇点 → 入环点（继续向前）的距离
```

#### 结论怎么落地成代码？

从 **head** 拿个指针 `p`（走 x 步到入环），
从 **相遇点** 拿 slow 自己（走 z 步到入环），
因为 `x = z`，两者一步一步同步走 → **必然在入环点相撞**。

---

### 完整代码（Python）

```python
from typing import Optional

class ListNode:
    def __init__(self, x):
        self.val = x
        self.next = None

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        slow = head
        fast = head

        # =============== Step 1：找相遇点（判环） ===============
        while fast and fast.next:
            slow = slow.next            # 1 步
            fast = fast.next.next       # 2 步

            if slow is fast:            # 相遇 = 有环
                # ============= Step 2：对齐找入口 ==============
                p = head                # p 从头（要走 x 步）
                while p is not slow:    # slow 从相遇点（要走 z 步）
                    p = p.next
                    slow = slow.next
                return p                # x == z，必在入口相遇

        # fast / fast.next 为空 → 无环
        return None
```

---

### 完整模拟（题解官方示例）

**链表：`3 → 2 → 0 → -4 → (回 2)`，入环点 = 2**

```
Step 1：找相遇点
  起点  slow=3  fast=3
  1轮   slow=2  fast=0
  2轮   slow=0  fast=2
  3轮   slow=-4 fast=-4   ✅ 相遇在 -4

  此时对照图示：
    x = 1（head=3 → 入环点2）
    y = 2（入环点2 → 相遇点-4，步数：2→0→-4 = 2 步）
    z = 1（相遇点-4 → 入环点2，步数：-4→2 = 1 步）
    ❓ 这里 x=1，z=1，满足 x = z ✔️（n=1 结论成立）

Step 2：p=head(3)，slow=相遇点(-4)，同步前进
  1轮  p=2  slow=2   ✅ p == slow → return 2
```

**结果正确，入口就是节点 2。**

## 📊 两套解法对比

| 解法 | 时间 | 空间 | 面试保底 | 面试进阶 | 核心逻辑 |
|------|------|------|---------|---------|---------|
| **哈希集合** | O(n) | O(n) | ✅ 首选兜底，不容易写错 | 能过但非最优 | 第一个重复节点 = 入口 |
| **快慢指针** | O(n) | **O(1)** | 需要公式记忆 | ⭐ 面试官期望 | 判环 + x=z 同步对齐入口 |

## 🔗 横向打通：链表查找题「暴力 vs 最优」规律

| 题目 | 暴力（Set 换简单） | 最优双指针（控空间） | 双指针支撑 |
|------|------------------|---------------------|-----------|
| LC160 相交链 | A 全存 Set，B 遍历找第一命中 | 交换链表走 / 长度对齐 | a+c+b = b+c+a |
| LC142 环形 | 存所有节点，找第一个重复 | 快慢判环 + 同步对撞 | x = z |
| LC209 子数组和 | 双层枚举所有区间 | 滑动窗口（同向） | 正数单调性 |
| LC977 平方有序 | 平方后全排序 | 相向双指针擂台 | 极值在两端 |

> 🔥 **万能规律**：
>
> - 链表查找类暴力 = **牺牲 Set 空间换无脑逻辑**
> - 最优解 = **设计指针移动规则 + 数学/单调性/路程守恒支撑，省下空间**

## ⚠️ 高频错误清单

| 错误 | 原因 | 正确姿势 |
|------|------|---------|
| 相遇点直接 return 当入口 | 混淆「判环」和「定位入口」 | 相遇后加 p=head 和 slow 同步走 |
| while 条件漏写 fast.next 判空 | fast.next.next 会 NPE | `while fast and fast.next` |
| 比较用 `==` 不用 `is` | 比较 val 还是对象？ | 节点比较永远 `is`，对象身份才是真 |
| 想不出来还死磕快慢 | 考试时间有限 | 写 Set 版先过，再补快慢思路 |

## 🧭 和 LC141 的关系

写 LC141（只判有没有环）可以直接写 Step 1 的循环：

```python
def hasCycle(self, head: Optional[ListNode]) -> bool:
    slow = head
    fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False
```
