# 数组章节总复习：5 大手法 + 识别指纹地图

> **参考**：[代码随想录 - 数组总结](https://programmercarl.com/algo/array/array-summary.html)
>
> **核心目的**：不是把 5 道题再过一遍，而是回答你最关心的问题：
>
> **拿到一道陌生数组题，我凭什么瞬间想到应该用「二分 / 双指针 / 滑动窗口 / 模拟 / 前缀和」中的哪一个？**
>
> 每一种手法都会给你一张「识别指纹卡」——看到什么关键词、满足什么前提，直接就判定走哪条路线。

---

## 📋 数组基础知识回顾

| 性质 | 含义 | 后果 |
|------|------|------|
| **连续内存存储** | 元素一个挨一个存 | 下标访问：**O(1)** |
| **同类型且定长元素** | 地址 = 首地址 + 下标 × 元素大小 | 才能支持随机访问 |
| **插入/删除必须移动后面所有元素** | 后面的元素整体平移 | 插入删除：**O(n)** |
| **二维数组**：C++ 连续 / Java & Python 不连续（每一行是独立数组对象） | | 不能假设行之间紧挨着 |

> 💡 **数组的根本矛盾**：查得快（O(1)）但改得慢（O(n)）。
>
> 所有数组优化手法，都是在「**尽量不做移动元素的 O(n) 操作**」上想办法。

## 🧭 5 + 1 种手法总览（一眼判定表）

| 手法 | 识别指纹关键词 | 最典型题目 | 时间复杂度能到 |
|------|--------------|-----------|--------------|
| ① 二分查找 | **有序** + **查找特定值 / 插入位置 / 第一个满足条件** | LC704 | O(log n) |
| ② 快慢双指针（同向） | **原地修改 / 删除满足条件的元素** / 不额外开数组 | LC27 移除元素 | O(n) |
| ③ 相向对撞指针 | **有序数组的结果两端有极值** / 需要同时看最左和最右 | LC977 有序数组平方 | O(n) |
| ④ 同向滑动窗口 | **连续子数组** + **指标具备单调性**（正数和、种类数等） | LC209 最小子数组和 | O(n) |
| ⑤ 螺旋 / 边界模拟 | 没有数据结构优化空间，纯粹「按规则走路」+ **统一区间规则** | LC59 螺旋矩阵 II | O(n²) ~ O(nm) |
| ⑥ 前缀和 | **多次查询区间和** / 换元把区间和变成两个前缀差 | 区间和、开发商买土地 | 构造 O(n) + 查询 O(1) |

## ① 二分查找 🎯

### 🔍 识别指纹（看到就想到二分）

```
必须同时满足：
  1. 数组有序（或可以转化成有序序列判断）
  2. 问题是「查找」型：找某个值 / 找第一个满足条件 / 找插入位置
  3. 每次比较后能彻底排除一半答案
```

典型题目描述的信号词：

> - "给定有序数组 nums…"
> - "时间复杂度要求 O(log n)"
> - "找到第一个 >= target 的位置"

**反例（不是二分）**：「查找」但数组无序 → 先排序再二分或直接 O(n) 扫。

### ✅ 成立前提

- 序列必须**有序**（或者判断条件具备单调特性，比如「只要位置 i 满足，所有 >i 都满足」就相当于有序）
- 每次判断后可以**明确放弃一半搜索空间**（否则不能砍成 log n）

### 🧠 核心思想

暴力遍历 O(n) → 每次比较**排除一半答案**，用 2^k 次判断就够了，所以复杂度 log₂n。

### 📝 模板（左闭右闭标准版）

```python
def binary_search(nums, target):
    left = 0
    right = len(nums) - 1        # 左闭右闭 [left, right]
    
    while left <= right:         # 含 ==，因为单个元素区间 [2,2] 合法
        mid = left + (right - left) // 2   # 防整数溢出
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1       # 新搜索范围 [mid+1, right]
        else:
            right = mid - 1      # 新搜索范围 [left, mid-1]
    return -1
```

**核心口诀**：`mid < target → left = mid + 1`；`mid > target → right = mid - 1`；
**循环不变量**：永远保持搜索空间是**左闭右闭**，所有边界从这一条规则推出。

### 🏠 家族题目

| 题号 | 变化点 |
|------|-------|
| LC704 二分查找（标准原版） | 基础模板 |
| LC35 搜索插入位置 | 找不到时返回应插入位置 = left |
| LC34 排序数组中查找元素的第一个和最后一个位置 | 分两次二分：找左边界 + 找右边界 |
| LC69 x 的平方根 | 隐藏有序（整数 0..x 本身就是天然有序），mid*mid 判断 |
| LC367 有效的完全平方数 | 同上，返回布尔值 |

### ❌ 高频踩坑

- `left + (right - left) // 2` 千万不要写 `(left+right)//2`，大数组会溢出
- 写 `[left, right]` 闭区间 → `while left <= right` + `right = mid - 1`，不要和左闭右开混着来（破坏循环不变量）

## ② 快慢双指针（同向）🏃‍♂️

### 🔍 识别指纹

```
必须出现：
  1. 需要「原地」修改数组（不希望额外开 O(n) 数组）
  2. 操作是：筛选 / 删除 / 替换 满足条件的元素
  3. 输出结果是「筛选后的新数组 / 新数组长度」
```

典型信号词：

> - "原地修改"、"空间 O(1)"
> - "移除所有等于 val 的元素"
> - "去重"、"保留只出现一次的元素"

### ✅ 成立前提

- 修改规则是**单向**的：一个元素只要被「快指针」扫描一次，就能决定要不要留下
- 不需要回头再判断（如果要回头看，通常会变成其他类问题）

### 🧠 核心思想

```
快指针 fast：遍历原始数组每个元素，判断「是好元素还是坏元素」
慢指针 slow：永远指向「下一个好元素应该存放的位置」

fast 每遇到一个好元素 → 赋值给 slow 位置 → slow 前进
```

本质：把「两层 for 删除（O(n²)）」改成「收集好元素」，一次遍历完成。

### 📝 模板

```python
def removeElement(nums, val):
    slow = 0
    for fast in range(len(nums)):        # fast 一个不落全跑
        if nums[fast] != val:            # 判定：当前是"好元素"吗？
            nums[slow] = nums[fast]      # 是就放到 slow 位置
            slow += 1                    # slow 挪到下一个空位
    return slow                          # slow 刚好 = 好元素总个数
```

**口诀**：**快扫判好坏，慢放收结果**（传送带模型：快带货物来，慢收合格的）

### 🏠 家族题目

| 题号 | 变化点 |
|------|-------|
| LC27 移除元素 | 原版模板 |
| LC26 删除有序数组中的重复项 | 好元素判定：`nums[fast] != nums[slow-1]`（跟慢指针前一个比） |
| LC283 移动零 | 删除 0 的等价版：把非 0 收前面，后面位置统一填 0 |
| LC844 比较含退格的字符串 | 需要额外从后往前扫，或者构造退格后的串再比较 |

### ❌ 高频踩坑

- 不要写成 `nums.pop(n)`——pop 内部也要移动元素，等于又把 O(n) 搬回来了
- 不要让 fast 跳过好元素——fast 必须从头到尾全跑，每个都判一次

## ③ 相向对撞指针 🥊（两端擂台）

### 🔍 识别指纹

```
必须出现：
  1. 原始数组有序（或平方后、绝对值后有极值规律）
  2. 最大值 / 最小值 / 结果极值 **只能出现在数组两端**
  3. 我们只需要看「左端点 vs 右端点」谁更极端，不需要判断中间
```

典型信号词：

> - "有序数组平方后排序"
> - "两数之和（有序版）"
> - "盛最多水的容器"（两端高度决定面积）

### ✅ 成立前提

- **极值只能出现在两端**（这是它和同向快慢指针、滑动窗口的根本分界）
- 不能有回头需求：两端对撞一步步向内缩，不会再倒回去判断外面

### 🧠 核心思想

两端擂台比武：谁更极端谁先上台（填入结果），赢的那一边指针向内收缩。

```
  左端选手    ←──── 中间结果区 ────→    右端选手
    left                                        right
```

**为什么 LC977 要从后往前填结果？**

因为两端能稳定拿到**最大绝对值**（擂台胜者是更大的数），所以结果数组必须从尾部开始放最大的，最后头自然就是最小的。

### 📝 模板（LC977 有序数组平方）

```python
def sortedSquares(nums):
    n = len(nums)
    res = [0] * n
    left, right = 0, n - 1
    k = n - 1                       # k 指向结果尾部（从大往小放）
    
    while left <= right:
        L2 = nums[left] ** 2
        R2 = nums[right] ** 2
        if L2 < R2:                 # 右端选手赢
            res[k] = R2
            right -= 1
        else:                       # 左端选手赢（或相等都行）
            res[k] = L2
            left += 1
        k -= 1
    return res
```

**口诀**：**两端比极端，赢的上台收，k 倒着填。**

### 🏠 家族题目

| 题号 | 变化点 |
|------|-------|
| LC977 有序数组平方 | 绝对值大的赢，结果倒填 |
| LC167 两数之和 II（有序数组） | 和 < target 左移；和 > target 右移；= 就返回 |
| LC11 盛最多水的容器 | 两端中更**短**的那个先内缩（贪心理由：短板决定容量） |
| LC15 三数之和 | 先排序 → 外层固定一个 + 内层两数之和的相向对撞 |

### ❌ 高频踩坑

- 用这道题一定要能说清「**为什么极值只在两端**」——说不出来就不要乱用
- LC977 不要从前往后填结果（你拿到的是最大的，放前面最后必然还得排序一遍，白忙）

## ④ 同向滑动窗口 ⚖️（捕虫网）

### 🔍 识别指纹

```
必须出现：
  1. 求「连续子数组」相关答案（长度 / 个数 / 和）
  2. 能定义一个窗口指标 f(l, r)，并且满足：
       r 右移一格 → f(l, r+1) 单调不减
       l 右移一格 → f(l+1, r) 单调不增
```

典型信号词：

> - "长度最小的子数组，满足和 ≥ target"
> - "最长不含重复字符的子串"
> - "子数组中不同整数个数最多 K 个"
> - 暗示单调的条件：**"全部是正整数"**（一看到正整数 + 连续子数组 + 和 → 滑窗反射）

### ✅ 成立前提（灵魂）

**单调性必须成立。** 反例：数组有负数 / 0 → 左移收缩窗口总和可能反而变大 → right 不回退的推论崩塌 → 滑窗直接失效。

### 🧠 核心思想

```
暴力：起点 i 变 → 终点 j 推倒重来（O(n²)）
滑动窗口：利用单调性砍掉「回退的无效搜索」
  left、right 都只前进不回头
  每个元素最多进窗口一次、出窗口一次 → 总扫描 ≤ 2n = O(n)
```

### 📝 模板（LC209 最短子数组和）

```python
def minSubArrayLen(target, nums):
    left = 0
    total = 0
    min_len = float('inf')
    
    for right in range(len(nums)):      # ① 右扩张
        total += nums[right]
        while total >= target:          # ② while 持续收缩（必须 while，不能 if！）
            min_len = min(min_len, right - left + 1)
            total -= nums[left]
            left += 1
    return min_len if min_len != float('inf') else 0
```

**口诀**：**右扩 → 满足就 while 左收 → 最后判无解**

### 🏠 家族题目

| 题号 | 指标 f(l,r) | 收缩条件 |
|------|------------|---------|
| LC209 最小子数组和 | 窗口内元素之和（正数=单调） | total ≥ target 收 |
| LC3 无重复最长子串 | 字符是否重复出现（set 判） | 出现重复就收 |
| LC904 水果成篮 | 篮子种类数（最多 2 种） | 种类 > 2 收 |
| LC76 最小覆盖子串 | t 串字符是否都覆盖到 | 一旦全覆盖就往死里收 |

### ❌ 高频踩坑（三大脑补坑）

| 坑 | 后果 |
|----|------|
| ❌ 收缩用 `if` 不用 `while` | 漏掉「收缩一次后依然合法、还能更短」的最优解 |
| ❌ 有负数 / 0 还硬套 | 单调性崩塌，right 不回退会丢正确范围 |
| ❌ min_len 初始为 0 / 最后忘记判断 | 结果永远 0 或无解返回无穷 |

## ⑤ 螺旋 / 边界模拟 🌀（循环不变量）

### 🔍 识别指纹

```
必须出现：
  1. 没有任何数据结构上的优化空间（既不能二分、也不能双指针剪枝）
  2. 题目就是让你「按几何规则填充 / 读取」：螺旋、之字形、对角线、顺时针旋转
  3. 核心矛盾不是算法快慢，是「边界别写错」
```

典型信号词：

> - "螺旋矩阵"、"顺时针旋转矩阵"、"对角线遍历"
> - "n × n 矩阵按顺序填入 1 到 n²"

### ✅ 成立前提

- 这是一类**模拟题**，别想靠排序、双指针砍复杂度；复杂度本来就是 O(nm) 要全部填完
- 重点是**边界规则统一**（循环不变量），而不是聪明

### 🧠 核心思想

```
所有边统一采用同一种区间开闭（推荐：左闭右开 [start, end)）
→ 拐角点永远交给下一条边处理
→ 任何两条边永远不会在同一个拐角写两次，也不会漏掉
```

没有统一规则 → 一条边左闭右闭、另一条左闭右开 → 拐角重复赋值 / 漏赋值，必崩。

### 📝 模板（LC59 螺旋矩阵 II，左闭右开标准版）

```python
def generateMatrix(n):
    res = [[0]*n for _ in range(n)]
    startx, starty = 0, 0
    loop = n // 2
    offset = 1
    num = 1
    mid = n // 2

    while loop > 0:
        i, j = startx, starty
        # 上行：左→右，[starty, n-offset)
        for j in range(starty, n - offset):
            res[i][j] = num; num += 1
        # 右列：上→下
        for i in range(startx, n - offset):
            res[i][j] = num; num += 1
        # 下行：右→左
        for j in range(n - offset, starty, -1):
            res[i][j] = num; num += 1
        # 左列：下→上
        for i in range(n - offset, startx, -1):
            res[i][j] = num; num += 1
        startx += 1; starty += 1
        offset += 1; loop -= 1

    if n % 2 == 1:
        res[mid][mid] = num
    return res
```

**口诀**：**一圈四条边，统一左闭右开；奇数最后补中心。**

### 🏠 家族题目

| 题号 | 变化点 |
|------|-------|
| LC59 螺旋矩阵 II（生成） | 填入 1 到 n²，标准模板 |
| LC54 螺旋矩阵（读取） | 读取已有矩阵元素；需要维护 top/bottom/left/right 四边界，一圈圈收缩 |
| 程序员面试金典 旋转矩阵 90° | 另一种模拟：先水平翻转 + 再对角线交换（两行代码技巧） |

### ❌ 高频踩坑

- **千万别写 `[[0]*n]*n` 创建矩阵** → 所有行共享同一个引用对象，改一行全改
- 四条边的区间一旦有一条写成左闭右闭 → 拐角重复 bug
- 忘记奇数 n 单独填中心（n=3 时中间那个 9）

## ⑥ 前缀和 ➕（拓展手法）

### 🔍 识别指纹

```
必须出现：
  1. 需求是「多次查询某个区间的和」（只查一次直接累加就行，不用前缀）
  2. 或者可以把「区间和 S(i,j)」化简表示成「两个前缀和相减」
```

典型信号词：

> - "查询区间和 Q 次"
> - "子数组和为 K 的个数"
> - "开发商两块土地取走后，剩余最大差值"（本章节拓展练习题）

### ✅ 成立前提

- 所有查询不会修改数组（如果要改，用树状数组 / 线段树，不在这里）
- 可以预处理一个前缀数组 `prefix[i] = nums[0..i-1]` 之和

### 🧠 核心思想

```
一次构造 prefix：prefix[0]=0, prefix[1]=nums[0], prefix[2]=nums[0]+nums[1] ...
任何区间和 S(i..j-1)  = prefix[j] - prefix[i]

构造：O(n) 一次，之后所有查询 O(1)。
总查询量越大，收益越高。
```

### 📝 模板

```python
def build_prefix(nums):
    n = len(nums)
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i+1] = prefix[i] + nums[i]
    return prefix

# 查询区间 [i, j-1]（从 i 到 j-1 的闭区间和）
def range_sum(prefix, i, j):
    return prefix[j] - prefix[i]
```

**口诀**：**构造前缀多一位，任意区间差一对。**

### 🏠 家族题目

| 题号 / 练习 | 变化点 |
|------------|-------|
| 本章节 6.区间和（卡码网） | 标准模板 |
| 本章节 7.开发商购买土地 | 把「土地总和」分成四块，四象限前缀和分别算 |
| LC560 和为 K 的子数组 | prefix[j] - prefix[i] = K → 用哈希表 + 前缀和组合 O(n) |
| LC304 二维区域和检索 | 二维前缀和，容斥原理计算 |

### ❌ 高频踩坑

- 忘了 `prefix[0] = 0` 这一位 → 取 `[0, j]` 区间和时要用 `prefix[j] - prefix[0]`，少了这一位就得特殊处理
- 数组有负数时前缀和依然正确（前缀和本身不要求正）

## 🗺️ 新题场景判定流程图（最重要一节 ⭐）

拿到一道数组题，按下面顺序依次问自己：

```
Step 1：这道题是纯「按规则走格子 / 按方向遍历」吗？
  ✅ 是 → 手法 ⑤ 模拟（循环不变量统一边界规则）
  ❌ 否 → 进入 Step 2

Step 2：题目关键词是「连续子数组」？
  ✅ 是 → 进入 Step 2a
          Step 2a：定义一个窗口指标 f(l,r)，r 扩 / l 收 时指标单调吗？
                    ✅ 单调 → 手法 ④ 同向滑动窗口
                    ❌ 不确定 / 有负数 → 前缀和 / 暴力 / 其他方法
  ❌ 否 → 进入 Step 3

Step 3：数组是有序的（或能转化为有序判断）+ 目标是「查找某个值 / 位置」？
  ✅ 是 → 手法 ① 二分查找（循环不变量：左闭右闭 / 左闭右开 选一个贯彻到底）
  ❌ 否 → 进入 Step 4

Step 4：题目说「原地修改 / 不额外开数组」+ 是筛选/删除满足条件的元素？
  ✅ 是 → 手法 ② 快慢双指针（快扫判好坏，慢放收结果）
  ❌ 否 → 进入 Step 5

Step 5：能定义「两端擂台」吗？即最大 / 最小结果值一定出现在两端？
  ✅ 是 → 手法 ③ 相向对撞指针
  ❌ 否 → 进入 Step 6

Step 6：需求是「多次查询区间和」？
  ✅ 是 → 手法 ⑥ 前缀和
  ❌ 否 → 想暴力 O(n²) / 排序 → 再想有没有其他优化
```

> 这张流程图就是你以后刷题的「导航地图」。
>
> **不要凭印象写题**——先按这 6 步判走哪条路，再从对应手法调模板。

## 🔬 场景判定小测（7 分钟自测）

下面给你 7 道题（有原题有变形），**不写代码，只判应该用哪号手法**。答案在最后。

| # | 题目描述（只看描述不用做） | 你选的手法 |
|---|--------------------------|-----------|
| 1 | 给定升序数组 `nums`，找 `target` 第一次出现和最后一次出现的位置 | |
| 2 | 给定数组，原地删掉所有偶数，返回剩余奇数的新长度（O(1) 空间要求） | |
| 3 | 正整数数组 `nums` + target，求和 == target 的子数组一共有几个（注意是「等于」不是「≥」） | |
| 4 | 升序数组 + 升序数组，合并成一个升序大数组，不能用额外空间原地合并（提示：从尾巴倒填） | |
| 5 | 给 n×n 矩阵，要求「Z 字形」遍历输出所有元素（第一行 → 第二行斜走 …） | |
| 6 | 给定一个整数数组（可正可负）+ K，问有没有一个子区间的和正好等于 K，要求 O(n) | |
| 7 | 给定正整数数组 nums，问能不能把数组切成三段非空连续部分，每段和都相等 | |

### 参考答案 + 判定理由

1. **① 二分查找**：数组有序 + 查找位置 → 标准二分（两次：找左边界 + 找右边界）
2. **② 快慢双指针**：原地删 + O(1) 空间 + 筛选条件（奇数=好元素）→ 快慢模板，把 `nums[fast] % 2 == 1` 当好元素判断
3. **④ 同向滑动窗口 / ⑥ 前缀和 都行**：正整数→单调，等于条件只要稍微改收缩条件（total>target 时收，total==target 时计数 + 收）。也能用前缀和 + 哈希表计数。
4. **③ 变种对撞指针**：有序数组合并不需要真擂台，两个指针 i、j 各从自己尾部往前、大的那个倒填进结果。核心还是「只需要比较两端大小就能决定下一步」。
5. **⑤ 边界模拟**：按 Z 字形规则走——不是数据结构优化题，是边界条件统一规则模拟题（每一步方向：左下 / 右上切换）。
6. **⑥ 前缀和 + 哈希表**：因为有负数，单调性直接没了，不能滑窗。用 `prefix[j] - prefix[i] = K`，hash 记录见过哪些 `prefix[i]` 以及次数。
7. **④ 同向滑动窗口（最推荐）**：全正整数 → 单调性成立。目标「三等分」转化为：找第一段和=total/3 的位置，再看第二段能不能凑同样的数。或者用前缀和：先找 prefix[i] = total/3 的 i，再找 prefix[j] = 2×total/3 的 j，看 j<n。

**评分参考**：判对 6 道以上 → 识别指纹已经彻底掌握；判对 4~5 道 → 大体没问题，把错的那两题对应手法再回去复习一遍；≤3 道 → 先别急着刷新题，把本节 5+1 张手法卡片再看一遍。

## 📌 最后一句话总结数组章

```
数组章只教会你 6 件兵器：
  二分       = 砍半查找，前提有序
  快慢指针   = 前后两个指针同向走，原地收好元素
  相向对撞   = 两端有极值，擂台往里缩
  滑动窗口   = 连续子数组 + 单调性，左收右扩不回头
  螺旋模拟   = 不靠聪明靠规则统一，循环不变量是生命线
  前缀和     = 区间和查询 = 两前缀差

关键不在于「写对模板」，而在于「看到题先判用哪件兵器」——识别指纹 > 背代码。
```
