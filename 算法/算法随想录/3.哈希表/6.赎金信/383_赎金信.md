# LeetCode 383 - 赎金信

> 📌 **题面一句话**：给你两个字符串 `ransomNote` 和 `magazine`，判断 `ransomNote` 能不能由 `magazine` 里面的字符**拼出来**。
> 关键约束：`magazine` 中的每个字符**只能在 ransomNote 中使用一次**；输入只有 26 个小写英文字母。
> 返回 True / False。

---

## 🎯 一句话核心定性：与 LC 242 字母异位词是「包含关系」，异位词是严格子集

这两道题长得极像，但**判定规则从"双向相等"放宽成了"单向够用"**，是 242 的弱化版：

| 题目 | 判定规则 | 数学表达（设 cnt_x[c] 为字符串 x 中字符 c 的出现次数）| 典型例子 |
|------|---------|-----------------------------------------------------|---------|
| **LC 242 有效的字母异位词** | **双向相等**：s 能拼成 t，t 也能拼成 s，两字符串每个字母频次**完全一样** | 对所有字母 `c`：`cnt_s[c] == cnt_t[c]`（且长度天然相等）| anagram ↔ nagaram：计数两边完全对等 |
| **LC 383 赎金信**（👈 本题）| **单向满足**：只要求 ransomNote 每个字符数量 ≤ magazine 对应字符数量，杂志**允许有多余字符** | 对所有字母 `c`：`cnt_ransom[c] ≤ cnt_mag[c]`（长度可以完全不一样）| ransom="aa"，mag="aab"：a:2≤2 ✅，b:0≤1 ✅ → True；但反过来"aab"绝对不能由"aa"拼成 ❌ |

> 🔺 **包含关系一句话**：**满足异位词的两对字符串，一定满足赎金信规则；满足赎金信规则的两对字符串，不一定是异位词。**
> 比如 `s="abc", t="aabbcc"`：赎金信判断 True，但不是字母异位词。

---

## 🧠 解题流程：和 LC 242 90% 一样，只有**最后一步判定条件**不一样

两道题都是**固定长度 26 的数组哈希**（因为只有小写字母，范围小且连续），核心都是「先加后减」：

| 步骤 | LC 242 有效的字母异位词 | LC 383 赎金信（👈 本题）|
|------|----------------------|---------------------|
| 前置快判 | ✅ 先判 `len(s) != len(t)`，长度不等直接返回 False（因为双向相等必须等长）| ❌ **绝对不能写长度前置判断**！ransom 可以比 magazine 短，比如 ransom=ab（长度2）+ mag=aabb（长度4）是合法的 True；就算 ransom 更长一点理论上也能先跑，直接中途遇到负数返回 False |
| 数组初始化 | `cnt = [0] * 26` | `count = [0] * 26` |
| 第一步（先加：存"库存"）| 遍历 s（第一个字符串），每个字符位置 +1 | 遍历 `magazine`（杂志：库存来源），每个字符位置 +1 |
| 第二步（后减：扣"消耗"）| 遍历 t（第二个字符串），每个字符位置 -1 | 遍历 `ransomNote`（消耗方：要拼的内容），每个字符位置 -1 |
| **判定条件（核心差异 👈）**| **全部等于 0** 才 True（两个字符串互相抵消归零，一丝不多一丝不少）| **不许出现负数**，一旦负数立刻返回 False；遍历完没负 → True（允许数组里有正数：说明杂志还有剩，没关系）|

### 🎨 形象化记忆

```
LC 242 异位词 = 两人掰手腕：你出一拳我打一拳，最后两边平手归零才算赢
              s 加，t 减 → 清零 = 谁也没占便宜

LC 383 赎金信 = 从库存里取货：仓库（magazine）先把货全摆好
              客户（ransomNote）一个个往外拿
              拿成负数 = 仓库缺货 ❌
              最后货架上还有剩余（正数）= 完全没问题 ✅
```

## 💻 Python 完整可提交代码（数组哈希最优，O(1) 空间）

### 本题 LC 383 赎金信标准版

```python
class Solution:
    def canConstruct(self, ransomNote: str, magazine: str) -> bool:
        count = [0] * 26                     # 26 个小写字母固定数组，哈希 O(1) 空间
        # 先装货：统计杂志所有字符入库
        for c in magazine:
            count[ord(c) - ord('a')] += 1
        # 再消耗：赎金信每个字符扣一个库存
        for c in ransomNote:
            idx = ord(c) - ord('a')
            count[idx] -= 1
            if count[idx] < 0:              # ❗ 负数 = 杂志缺货，这个字不够用
                return False
        return True                          # 全部扣完都没负，成功
```

### 对照：LC 242 有效的字母异位词标准版（放在一起对比，差异只在最后判定）

```python
def isAnagram(s: str, t: str) -> bool:
    if len(s) != len(t):                   # 异位词必须等长，这里可以快判
        return False
    cnt = [0] * 26
    for c in s:
        cnt[ord(c) - ord('a')] += 1
    for c in t:
        cnt[ord(c) - ord('a')] -= 1
    return all(x == 0 for x in cnt)        # ❗ 必须全部归零（双向对等）
```

> 两道题代码前 80% 完全一样，差异只在**最后判定逻辑**和**是否有长度前置判断**。把它们放一起记，只记两个差异点就行。

## 🆚 相同点 & 不同点一表通吃

| 维度 | LC 242 有效的字母异位词 | LC 383 赎金信 |
|------|----------------------|------------|
| **输入字符范围** | 仅 26 个小写字母 | 仅 26 个小写字母 |
| **哈希选型** | 固定长度数组 [0]*26，O(1) 空间最优（不用 dict）| 固定长度数组 [0]*26，O(1) 空间最优（不用 dict）|
| **核心操作** | 频次统计，先 +1 后 -1 | 频次统计，先 +1 后 -1 |
| **暴力法时间** | 嵌套循环 O(n²) | 嵌套循环 O(n²) |
| **哈希法时间** | O(n)（两趟各 n 次）| O(n)（两趟各 n 次）|
| **🔴 判定规则** | 双向对等：**最终数组全部 = 0** | 单向够用：**数组任何元素不许 < 0，允许正数** |
| **🔴 长度前置快判** | ✅ 必须有：`len(s)!=len(t)` 直接 False | ❌ **绝对不能加**：长度不一样完全合法（等长也行，不等长也行，只要够用）|

### 🔑 最容易踩的坑（赎金信专属）

**❌ 错误写法**：开头加上
```python
if len(ransomNote) > len(magazine):
    return False
```
看起来逻辑对（"要拼的东西比仓库还长肯定不够"）——**其实是错的！**
因为 `len(ransomNote) > len(magazine)` 确实不可能满足（每个字符至少1个，总得够字符总数），所以这个判断本身逻辑没错，但**反过来**：很多人写反成 `len(ransomNote) != len(magazine)` 就返回 False，或者脑子一热参考异位词的前置判断写了长度不等快判，直接把正确答案判错。

**安全做法**：赎金信**不写任何长度前置判断**，直接跑数组扣库存。真的不够用时，负数判定自然会 catch 到。不要多此一举。

> 补充：`len(ransomNote) > len(magazine)` 这行加进去**逻辑上没问题、可以提速（比如 ransom 1000 字符 vs magazine 2 字符）**，但前提是你方向写对了、且明白这和异位词 `!=` 判断完全不是一回事。新手建议不要加，避免混淆。

## 🔗 哈希选型完整规则（串联本章全部 6 道题，一张表记住一辈子）

做到第 6 道哈希题了，把「什么时候用数组、什么时候用 set、什么时候用 dict」的**选型指纹**一次定死，以后看到题直接按信号选：

| 哈希选型 | 触发指纹（看到这些信号直接上！）| 本章对应题目 |
|---------|------------------------------|------------|
| **数组哈希 [0]*固定长度** | ✅ 值的范围 **小且连续固定**（比如 0~25 的 26 字母、0~1000 数字）<br>✅ 需要计数频次 | [242 有效的字母异位词](../1.有效的字母异位词/242_有效的字母异位词.md)、**383 赎金信 👈本题** |
| **Set** | ✅ **只判断是否存在，不需要计数、不需要绑下标**（只要知道"有/没有"）<br>✅ 附带要去重 | [349 两个数组的交集](../2.两个数组的交集/349_两个数组的交集.md)、[202 快乐数](../3.快乐数/202_快乐数.md)（循环检测看有没有见过这个数）|
| **Dict / Map**（value 存附加信息）| ✅ 需要计数频次，且**值的范围不是固定小范围**（int 全范围、负数都可能）<br>✅ 需要绑定额外信息：**存下标**（要返回索引）、**存出现次数**（要累加方案数）<br>✅ key 不是连续整数（比如字符串当 key）| [1 两数之和](../4.俩数之和/1_两数之和.md)（value 存下标，返回索引对）、[454 四数相加 II](../5.四数相加II/454_四数相加II.md)（value 存和出现的次数，累加方案数）|

### 极简记忆口诀（3 句）

> **范围固定连续小 → 数组**（242、383）
> **只问有不有 → Set**（349、202）
> **要记次数 / 要绑下标 / 范围大 → Dict**（1、454）

## 🧱 固化思考模板 + 最终记忆口诀

### 赎金信 / 异位词通用思考 3 步

```
Step 1 审题两道判断题：
  ├─ Q1：是不是只有小写 26 字母？→ 是 → 数组哈希 [0]*26，不用 dict
  └─ Q2：判定规则是"双向对等(异位词)"还是"单向够用(赎金信)"？

Step 2 先加后减固定流程：
  ├─ 异位词：s +1 → t -1
  └─ 赎金信：杂志(magazine) +1 → 赎金(ransomNote) -1

Step 3 最后判定（唯一差异点）：
  ├─ 异位词：长度要等长前置判 + 最终 all==0
  └─ 赎金信：不要长度快判 + 中途负数就 False，跑完 True
```

### 🔚 最后 2 句终极口诀，刻进大脑

> **异位词：两边互消，归零过关**
> **赎金信：杂志库存扣减，不许透支负数**
