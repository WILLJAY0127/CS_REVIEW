# 结论先说

**Java 基础不是背 API，而是「所有上层知识（JVM / 并发 / Spring）的地基」，资深后端面试一定会考察，但考察方式和应届生完全不一样。**

> 区分两层：
>
> 1. 浅度基础（应届生）：`String`、`ArrayList`、接口和抽象类、== 和 equals，背概念。
> 2. 资深 P6/P7 的基础：**基础语法 / API 背后的语言契约，用来支撑 JLS、JVM、并发的推理**。

## 核心：哪些基础要掌握，哪些可以浅尝

### ✅ 必须掌握（和你现在学的 JVM、并发强绑定，不学这个，上层知识就无根）

这些不是孤立知识点，**是 JLS/JVMS 的组成部分**，是你前面整套体系的底层立足点：

1. **面向对象基础**
   - 继承、重写、重载、多态；访问修饰符；接口 vs 抽象类；
   - 重点：方法重写的规则（协变返回、异常声明），静态方法不存在重写。
   > 关联场景：AOP 代理、动态代理、多态，底层依赖这套规则。
2. **equals /hashCode 契约（JLS 规定的契约）**

   &#x20;契约：equals 相等则 hashCode 必须相等；反过来不强制。
   > 业务坑：放入 HashMap、HashSet，如果重写 equals 不重写 hashCode，集合直接异常。并发场景下也会踩坑。
3. **String、常量池**

   &#x20;理解`String`不可变（`final char[]`），字符串常量池；
   > 关联：不可变对象天然线程安全，和并发里面 final 安全发布是一套思想。
4. **集合框架（重点看契约，而不是死记源码细节）**
   - List、Set、Map 接口契约；
   - ArrayList、LinkedHashMap、HashMap**对外行为**（HashMap 的哈希寻址、扩容、链表转红黑树的触发条件）
   > 注意：HashMap 底层链表红黑树属于**JDK 实现细节**；接口行为是契约。
   >
   > &#x20;面试考察：并发下 HashMap 为什么不安全（死循环、数据丢失），引出 ConcurrentHashMap。
5. **泛型、类型擦除**

   &#x20;类型擦除、上界`<? extends T>`、下界`<? super T>`。
   > 很多中间件、JDK 工具大量使用泛型；不懂擦除，看不懂很多框架源码。
6. **异常体系**

   &#x20;受检异常、非受检异常；什么时候抛，什么时候捕获。
   > 关联 Spring 事务：捕获异常不抛出，事务不回滚，就是这个基础知识点延伸出来的。
7. **内部类（静态内部类、成员内部类）**

   &#x20;DCL 单例、静态内部类单例，全部依赖内部类规则。

### ⚠️ 简单了解，不用深挖细节

- IO、NIO：知道 BIO/NIO/AIO 的行为差异；如果你的业务不是网络中间件开发，不用啃底层。
- 包装类：知道自动装箱拆箱，缓存（Integer -128\~127）即可。

### ❌ 可以几乎不花时间

- 简单 API 背诵：比如`Math`各种方法、Date 各种过时 API。
- 非常边角 API。

## 关键问题：资深面试怎么考 Java 基础？（和应届生完全不同）

应届生：

> 问：ArrayList 和 LinkedList 区别？背：数组连续、链表增删快。

资深后端（P6/P7）：

> 不会单独抽基础题，**基础会融合在并发、集合、框架问题里面一起考察**。
>
> &#x20;例子：

1. 问 ConcurrentHashMap，一定会问到 HashMap 为什么线程不安全（集合基础）
2. 问 DCL 单例，会问到 volatile + 静态内部类（内部类、final、并发基础）
3. 问缓存设计，问到不可变对象，追溯 String/final 基础
4. 问分布式 ID，会问到 hashCode，equals 契约

> 也就是说：**你前面学的 JLS、并发、Spring，很多推理的前提，就是 Java 基础的语言契约。基础薄弱，上层的逻辑链就会断掉。**

## 一个很重要的判断标准（帮你评估）

当你学习 JVM / 并发 / Spring 的时候，遇到下面情况，说明 Java 基础有缺口，需要补：

1. 看到泛型、类型擦除看不懂
2. 分不清接口和抽象类，分不清重载重写
3. 不清楚 equals/hashCode 契约
4. 不明白为什么 String 不可变、不可变对象线程安全

> 如果上面这些概念你能看懂，那基础不用从头到尾刷一遍；**只查漏补缺，不从头系统重学**。
>
> &#x20;不建议像应届生一样从头到尾刷《Java 编程思想》或者基础刷题集，性价比很低。

## 优先级（贴合你现在的学习路线）

你现在主线：JVM → Java 并发 → Spring

**Java 基础不单独开一个大阶段，边学主线边补缺口。**

&#x20;比如：学到 final 安全发布的时候，顺带巩固 final、不可变对象、equals/hashCode。学到 JUC 集合的时候，顺带复习 HashMap 的契约。

## 风险提醒

很多人学习路线的误区：

> 基础已经会了 → 直接猛攻 JVM、并发、Spring 底层
>
> &#x20;但是基础的**语言契约**模糊，学到上层的时候，推理经常卡壳，逻辑链断裂。
>
> &#x20;表现：看得懂结论，但是无法独立推导为什么，面试一问深挖就崩。

## 一句话总结

Java 基础**不需要像应届生那样从头到尾刷题背诵**，但基础里面的**语言契约（equals/hashCode、泛型、继承、集合接口契约、不可变对象）是必备的**，它是 JLS/JVM/ 并发这套体系的前置地基。

&#x20;采用「主线优先，遇到缺口就地补基础」策略，性价比最高。

你可以评估一下：泛型、equals\&hashCode、集合接口契约这几块，你有没有卡点？
