## 🔴 模块 3：Spring / SpringBoot / Spring 事务（资深必深挖）

**官方标准来源**

- Spring Framework 官方文档：[https://docs.spring.io/spring-framework/reference/](https://link.wtturl.cn/?target=https%3A%2F%2Fdocs.spring.io%2Fspring-framework%2Freference%2F\&scene=im\&aid=582478\&lang=zh "autolink")
- SpringBoot 官方文档：[https://docs.spring.io/spring-boot/reference/](https://link.wtturl.cn/?target=https%3A%2F%2Fdocs.spring.io%2Fspring-boot%2Freference%2F\&scene=im\&aid=582478\&lang=zh "autolink")

**核心内容**

1. Spring Core：Bean 生命周期、三级缓存解决循环依赖、IOC 容器
2. AOP：动态代理 JDK/CGLIB，切点、通知，AOP 失效场景
3. 事务：隔离级别、传播行为；**事务失效全部场景（重中之重）**
4. SpringBoot：自动装配、条件注解、starter 机制、配置加载优先级

**掌握程度**

&#x20;能讲原理、能说缺陷、场景题：事务嵌套、事务异步、事务传播选型。

**实操**：写 Demo 复现事务失效、循环依赖场景。

## 🔴 模块 4：MySQL & InnoDB（面试场景题占比最高）

**官方标准来源**

&#x20;MySQL 官方文档 [https://dev.mysql.com/doc/](https://link.wtturl.cn/?target=https%3A%2F%2Fdev.mysql.com%2Fdoc%2F\&scene=im\&aid=582478\&lang=zh "autolink")

> InnoDB 是 MySQL 官方存储引擎，所有 MVCC、锁、redo/undo log 以 MySQL 文档为准，网上很多总结简化有坑。

**核心内容**

1. InnoDB 底层：聚簇 / 二级索引，B + 树，页结构
2. MVCC、undo log、redo log，隔离级别
3. InnoDB 锁：行锁、意向锁、gap 临键锁，幻读
4. SQL 优化：explain 执行计划，索引失效场景
5. 大表 DDL、大事务风险、慢 SQL 排查流程
6. 分库分表：分片策略、分布式 ID、跨库 join、分页排序、扩容迁移问题

**掌握程度**

&#x20;能做 SQL 优化，能分析锁冲突，分库分表做技术选型评估，识别风险。

**实操**：explain 分析 SQL；复现 gap 锁；观察大事务 binlog。

## 🟡 模块 5：Redis

**官方标准来源**：Redis 官网文档 [https://redis.io/docs/](https://link.wtturl.cn/?target=https%3A%2F%2Fredis.io%2Fdocs%2F\&scene=im\&aid=582478\&lang=zh "autolink")

**核心内容**

1. 底层数据结构、对象编码
2. 持久化：RDB、AOF，各自优缺点、丢失数据风险
3. 缓存三大问题：穿透、击穿、雪崩；解决方案对比
4. 分布式锁（Redis 锁缺陷，主从切换丢锁问题）
5. 集群：主从复制、哨兵、RedisCluster，槽位迁移
6. 内存淘汰策略

**掌握程度**：方案选型、故障风险分析。

**实操**：搭建单机 / 主从；模拟缓存雪崩场景；redis-cli 监控。

**官方标准**

- RocketMQ：[https://rocketmq.apache.org/docs/](https://link.wtturl.cn/?target=https%3A%2F%2Frocketmq.apache.org%2Fdocs%2F\&scene=im\&aid=582478\&lang=zh "autolink")
- Kafka：[https://kafka.apache.org/documentation/](https://link.wtturl.cn/?target=https%3A%2F%2Fkafka.apache.org%2Fdocumentation%2F\&scene=im\&aid=582478\&lang=zh "autolink")

**掌握程度**：故障排查、方案取舍。

**实操**：本地搭建 MQ，模拟消息积压，死信。

## 🟡 模块 7：分布式基础（CAP、一致性、分布式事务、限流熔断）

> 这一块没有 “Java 语言规范”，是分布式理论，各组件遵守这套理论

1. CAP、BASE 理论，最终一致性
2. 分布式事务方案：2PC、TCC、SAGA、本地消息表。**选型对比、优缺点、成本**
3. 接口幂等性：各种实现方案（唯一索引、token、状态机）
4. 限流、熔断、降级（Sentinel 为主）：滑动窗口，半开状态，雪崩保护

**实操**：Sentinel 本地 demo，实现限流熔断。

## 🟢 模块 8：架构 & DDD（P7 区分项，业务技术经理重点考察）

无单一官方规范，领域驱动看《Domain-Driven Design》，微服务看 Martin Fowler 文章

1. 微服务拆分原则，拆分带来的代价（不是越拆越好）
2. 服务治理：注册中心 Nacos/Eureka、配置中心、链路追踪 Skywalking
3. DDD：限界上下文、聚合根、实体、值对象，领域事件
4. API 设计：接口版本、兼容性、向后兼容原则

> 考察形式：业务场景建模、系统设计题（订单、履约等）

## 🟢 模块 9：中间件 & 容器（按需，看岗位 JD，你前面关心 Docker 就在这里）

1. Docker：官方文档 docker docs，镜像、容器、volume、网络、Dockerfile、资源限制
2. 网关：Spring Cloud Gateway / Nginx，负载均衡策略，动态路由
3. ES（如果简历写了才深挖）：倒排索引、段、refresh/flush，分页、深度分页问题

## 🟢 模块 10：网络基础（TCP/HTTP，必懂基础，不会深挖源码）

参考：RFC 文档（TCP 是 RFC793，HTTP RFC）

&#x20;重点掌握：

&#x20;TCP 三次握手四次挥手、滑动窗口、拥塞控制、TIME\_WAIT；

&#x20;HTTP1.1/2/3 区别；HTTPS TLS 握手。

&#x20;场景：接口超时、连接池问题，经常和线上排查一起问。
