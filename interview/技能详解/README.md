## 两条复习主线

1. **硬技术线(1-4)**:八股 + 项目细节,手册第一篇(Q1~Q8)是题库,这里给地图和挂项目的方法。
2. **差异化线(5-9)**:别人没有你有的东西——保险资金一致性、AI 落地、核验中台、数据运营、带人,薪资溢价主要来自这部分。

## 复习节奏建议

- 每个文件夹 30~45 分钟:先看知识地图自查,标红不会的 → 回手册对应章节背 → 回到本文件"项目锚点"练口述。
- 优先序:**6 → 5 → 7 → 8 → 1~4 → 9**(差异化先占住,八股平时已熟,管理面考前突击)。
