# 技能 2:框架与微服务 — Spring 全家桶 + Spring Cloud

> 对应手册:第一篇 Q4(Spring)、Q8(分布式/微服务)

## 一、简历原句

> 精通 Spring Boot / Spring Cloud / Spring MVC / MyBatis,熟悉 IOC、Bean 生命周期、循环依赖三级缓存、AOP、事务管理源码;有 Nacos / Gateway / OpenFeign / Sentinel 微服务治理落地经验。

## 二、能力信号

- 这一档不考"会不会用",考**"框架替你做了什么"**:Bean 怎么生出来的、代理怎么织入的、事务为什么会失效。
- 微服务部分考**治理**:注册发现、配置热更新、限流降级、Feign 超时与重试怎么配——你做过平台,重点在"踩过什么坑、定过什么规范"。

## 三、知识地图

### Spring 核心

| 知识点 | 深度标尺 |
|---|---|
| IOC/Bean 生命周期 | 实例化 → 属性注入 → Aware 回调 → BeanPostProcessor 前置 → 初始化(@PostConstruct/InitializingBean/init-method)→ 后置 → 使用 → 销毁;**循环依赖三级缓存**(singletonObjects / earlySingletonObjects / singletonFactories)要能讲清为什么必须三级(AOP 提前代理) |
| AOP | JDK 动态代理(接口)vs CGLIB(子类);BeanPostProcessor 织入时机;环绕通知链(MethodInterceptor 责任链) |
| 事务 | `@Transactional` 失效八连:**自调用、非 public、异常被 catch、非 RuntimeException 默认不回滚、传播行为错、数据库引擎不支持、多线程、bean 未被 Spring 管理** |
| 传播行为 | REQUIRED/REQUIRES_NEW/NESTED 区别,能结合"主单入账 + 明细流水"场景讲 |
| MVC | DispatcherServlet 流程、拦截器 vs 过滤器、全局异常处理(@RestControllerAdvice) |
| 事件 | ApplicationEventPublisher;**`@TransactionalEventListener`(phase=AFTER_COMMIT)**:事务提交后再发,解决"消息发了事务回滚" |
| 自动配置 | spring.factories / AutoConfiguration.imports、@Conditional 系列、自定义 starter |

### Spring Cloud Alibaba

| 组件 | 你要会讲的点 |
|---|---|
| Nacos | 注册(CP/AP 临时实例)、配置中心、长轮询推送;`@RefreshScope` 热刷新原理(代理 + 重建) |
| OpenFeign | 超时/重试默认值坑(默认不重试)、连接池、**Feign 调用丢 header 怎么办**(RequestInterceptor 透传 traceId/用户态) |
| Gateway | 路由、全局过滤器、鉴权前置;和 Feign 拦截器配合做全链路 traceId |
| Sentinel | 流控( QPS/线程数)、熔断(慢调用/异常比例)、热点参数限流;**限流后兜底返回业务友好提示而不是报错** |
| 配置规范 | 开关分级:永久开关(功能裁剪)vs 临时开关(应急降级),过期开关要有清理机制 |

## 四、你的项目锚点

1. **零侵入埋点(断点平台)**:自定义注解 + Spring AOP/拦截器在关键节点上报事件——"AOP 不只是事务,能做架构抽象"的证据。
2. **开关化降级(核验中台)**:活体/比对/生存核验开关全部 Nacos 动态下发,`@RefreshScope` 秒级生效,挂"先有逃生通道再上线"的稳定性叙事。
3. **AI 工具白名单**:Dify Webhook 无登录态,用自定义注解 `@NoAuth` 加签名 + 内网放行,**不污染全局拦截器**——体现对 Spring MVC 拦截器链的理解(见手册 Q9.13)。
4. **Dify SSE 网关**:Spring Boot 3 + WebClient 做流式转发;可讲事件解析(MessageEvent/NodeFinishedEvent)。
5. **Feign 透传**:业务前台 → 核身引擎 → 三方,两层调用链 traceId 透传与统一异常转换。

## 五、高频追问

- "循环依赖三级缓存,两级行不行?" → 三级存的是 ObjectFactory,为了 AOP 代理只生成一次;构造器注入的循环依赖解决不了。
- "@Transactional 自调为什么失效?" → 代理对象没经过,走的是原始对象 this。
- "配置热刷新,`@Value` 打的属性会变吗?" → 不会,要 `@RefreshScope` 或 @ConfigurationProperties。
- "Feign 第一次调用很慢?" → 初始化负载均衡/连接建立;懒加载预热。
- "Sentinel 限流和 Redis 分布式限流怎么选?" → 单机阈值用 Sentinel,全局限流(如总 QPS 卖配额)用 Redis/Lua。
